## Shaders — FlowingGradient source adaptation

The first-conversation surface adapts the free MIT FlowingGradient kernel and its noise/field primitives to the existing Three.js/WebGL stack. The native `shaders` React package 4.0.5 was evaluated but removed after actual-browser visual and device-lifecycle failures; it is not a shipped runtime dependency. Upstream source reference: https://github.com/shader-effects-inc/shaders/tree/eb3df5cedc826008be8e1037c1182e649037c74a . No Pro presets, paid sections or editor assets were copied. Adapted upstream files: `packages/core/src/shaders/FlowingGradient/index.ts` (SHA-256 `7e30d231988daca4348b0e12d9902207d63e8e47637167a763da99098c003d32`), `gpu/kit/noise.ts` (`5817311eff374e9849aa4c0ea58a826c69e0f27696815dea109f395e7aad4cd4`), `gpu/kit/fields.ts` (`d789f0d13d92d0e20ecd66571814e7c78dcf54e3ace638120854500612ccf2e3`), and the corresponding `std/paint/fields.ts` / `materials.ts` composition definitions. ## MaterialX / Open Shading Language noise lineage

Shaders identifies its gradient-noise hash and constants as a MaterialX noise port. The local GLSL adaptation retains that lineage, modifies its syntax to GLSL ES 3, and uses only the 3D gradient-noise subset. Upstream references: https://github.com/AcademySoftwareFoundation/MaterialX/blob/main/libraries/stdlib/genglsl/lib/mx_noise.glsl and https://github.com/AcademySoftwareFoundation/MaterialX/blob/main/LICENSE . The inherited noise notice and MaterialX license follow. No MaterialX runtime is installed.

Noise Library.

This library is a modified version of the noise library found in
Open Shading Language:
github.com/imageworks/OpenShadingLanguage/blob/master/src/include/OSL/oslnoise.h

It contains the subset of noise types needed to implement the MaterialX
standard library. The modifications are mainly conversions from C++ to GLSL.
Produced results should be identical to the OSL noise functions.
