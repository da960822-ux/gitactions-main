# DOS implementation contract

Personal Korean/Spanish home for two people, led by user-supplied photos with the currently implemented games below. Keep the page modular so real additions can extend it without advertising unbuilt features. Korean/Spanish UI and recipient-language chat translation; original is always retained and displayed when translation is unavailable or the shared monthly character budget is exhausted. Seven-day retention. React/TypeScript static app deployable to Cloudflare Pages; Supabase anonymous Auth, Postgres and private Realtime. No billed LLM AI. No third-party code/assets copied without verifying terms.

Routes: / personal home (photos first, game choices below), /play lobby, /room/:id game room. The home must not connect to the backend. Missing credentials activate explicitly labelled same-browser local demo; NEVER represent local demo as internet multiplayer. Distinguish separate private server state from per-player view. Server is authoritative. Engine API in src/core/types.ts; deterministic seeds generated by server and never published. Version checks and request UUID enforce atomic actions. Private hands and catchmind answer remain server-side.

Games: davinci, catchmind, domino, jaipur, splendor, minhwatu, marble, rhythm. Rhythm is the original unmodified Music Talk Talk SWF with a self-hosted Ruffle player and source-page fallback; keep browser compatibility and redistribution-rights status explicit (see docs/RHYTHM.md). Standard base rules documented in both languages, explicit selected variation for minhwatu and Dominican domino, no invented universal standard. Core playable 1v1 domino first; AI/team modes marked unimplemented until actually working.

Owner: root handles shared contracts, secure backend/runtime and translation guard. Luna agents implement bounded game engines/tests, UI, documentation. No agent overwrites another owner's files. All engine errors null or stable readable string. Views contain available legal actions so generic UI can drive gameplay; normal actions in view.actions as {label: {ko,es}, action: GameAction}[]. Stable view fields: turn, phase, public board, own hand, opponent count, status/result. Can add fields as needed; UI must inspect concrete engines.
