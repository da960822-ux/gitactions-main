# 게임 개선 검증 기록

2026-10-11 로컬 개발 환경 기준. 부루마블, 다빈치, 캐치마인드를 병렬로 개선했다. 뮤직톡톡과 제외 요청한 게임은 이번 개선 대상에 포함하지 않았다. 배포는 수행하지 않았다.

## 구현 결과

- 부루마블: 중앙 세계지도, 24개 도시별 랜드마크, 6종 게임말, 3단계 건물, 소유권 카드 프레임을 실제 그래픽 자산으로 적용했다. 도시 선택 상세 카드에서 가격, 소유자, 건설비, 다음 통행료와 예상 잔액을 확인할 수 있다.
- 새 부루마블 방은 도시 가격에 따른 단계별 건설비를 사용한다. 기존 경제 버전의 방은 이전 비용 규칙을 유지한다. 이벤트의 지급 주체와 수취 주체, 실제 결제와 미납 금액을 구분하고 카드 표시 이후 효과음을 예약한다.
- 다빈치: 패와 행동 패널 배치, 공개 상태 아이콘, 조커 배치 미리보기, 확인·취소 및 키보드 포커스를 개선했다.
- 캐치마인드: 그래픽 도구와 라운드 상태 화면, 순서가 보장되는 그림 전송, 지연 중 그림 미리보기, 한 획 단위 실행 취소, 채우기 좌표 처리, IME 입력 중 전송 방지를 개선했다.

## 아직 검증하지 않은 범위

실제 두 기기에서 Supabase를 사용하는 온라인 대전과 재접속, 물리 키보드의 한국어 IME, 실제 네트워크 지연 및 장기 경제 밸런스는 별도 검증이 필요하다. 효과음은 표시 후 예약 시점을 확인했으며 실제 기기의 청취 지연은 측정하지 않았다. 모바일의 기존 게임 진입 제한은 유지했다.

캐치마인드 지우개는 종이색 `#fffefa`로 덮어 그리는 방식이다. 투명 레이어의 픽셀을 삭제하는 방식은 아니다. 색상·지우개·전체 삭제 스크린샷은 위 캐치마인드 폴더의 `catchmind-{color,eraser,clear}-1366x768-ko-{drawer,peer}.png`에 저장했다.

상용 게임 비교는 공개된 설계 특성을 기준으로 했다. 외부 상용 사이트 접근이 차단되어 최신 버전을 직접 플레이한 비교로 간주할 수 없다. 이번 변경만으로 상용화 품질을 달성했다고 판단하지 않는다.

그래픽 제작 계획과 출처·제작 방식은 [부루마블 제작 계획](MARBLE-VISUAL-PLAN.ko.md), [아트 기록](GAME-ART.md), [세계지도 제작 기록](marble-world-art.md)에 남겼다. 전체 문제 분석과 후속 개선은 [종합 검토](GAME-QUALITY-REVIEW.ko.md)를 참고한다.

## 초보자 설명 보강

사용자의 최종 범위 지정에 따라 다빈치·캐치마인드·부루마블만 수정했다. 다른 다섯 게임의 기존 안내는 유지했다. 한국어와 도미니카 사용자를 위한 자연스러운 스페인어로 목표, 세 단계 진행법, 핵심 주의점만 먼저 표시하고 기존 전체 규칙은 접힌 영역에 보존했다. 부루마블의 이전 저장 규칙은 해당 버전의 비용·대출·승리 조건을 안내한다.

세 게임의 실제 데모 화면을 언어별로 캡처한 이미지 여섯 장을 적용했다. 추가 합계는 159,304바이트이며 크게 보기 링크를 제공한다. [이미지 출처 및 제작 기록](GAME-GUIDE-ART.md)을 참고한다.

1366×768과 1440×900, 두 언어, 세 게임 조합 12건에서 게임 선택 전과 플레이 중 안내 총 24개 화면을 확인했다. 언어별 이미지 로딩, 세 단계 표시, 동일한 목표 문구, 세부 규칙 기본 접힘·클릭/Enter 펼치기, 가로 넘침 없음, 게임으로 돌아가기와 브라우저 오류 없음을 검사했다. 기록은 `/workspace/onboarding/beginner-guide-qa/report.json`, 화면은 같은 폴더의 PNG 파일이다. 초보자 사용자 대상 이해도 테스트와 도미니카 원어민의 최종 교정은 아직 수행하지 않았다.
