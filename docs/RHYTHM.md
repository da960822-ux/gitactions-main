# Music Talk Talk source and runtime

The local, unmodified game files are `public/rhythm/Music14.swf` and `public/rhythm/Music_RES.swf`. They came from the attachments on [Vidkidz's Music Talk Talk post](https://vidkidz.tistory.com/431), published December 20, 2020 and updated January 29, 2023. The post credits 제작 and 배급 to 한게임플래시 (Hangame Flash), and its author is 비드키즈 (Vidkidz). The post does not state a license for the SWF files; this records provenance, not a grant of redistribution rights. Keep these assets in the private project unless their rights are confirmed.

Both files are compressed SWF version 7 (`CWS`). `Music14.swf` is 1,369,431 bytes (1,897,726 bytes uncompressed, 550 × 450 px, 30 fps); `Music_RES.swf` is 414,619 bytes (436,670 bytes uncompressed, 550 × 400 px, 12 fps). The main SWF contains AVM1 `DoAction` and `DoInitAction` tags; the companion has no action tags. The main file also contains the original Hangame resource URL, so Ruffle's exact URL rewrite maps that request to the local, case-sensitive companion file. No proxy or remote content service is used.

The component uses the official `@ruffle-rs/ruffle` 0.7.1 self-hosted browser distribution. Its README recommends this bundle for websites and its JavaScript API; both hashed core chunks and both WASM modules are included because the loader references them. Ruffle is licensed under MIT OR Apache-2.0; both license texts are included in `public/rhythm/ruffle/`.

The article says to use the arrow keys and spacebar and warns that the game's “go to beginning” button can malfunction. Static inspection confirms a Flash 7 file and an external companion SWF reference, which the local rewrite is intended to address. A Chromium smoke check confirmed that Ruffle accepts the main SWF load, but emitted a hardware-acceleration warning. Gameplay, keyboard input, audio, and the companion SWF fetch were not verified, so full runtime compatibility remains pending. The player presents the original post as a fallback.
