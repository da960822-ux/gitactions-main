# 혼자 플레이 · AI 1대1과 2대2

게임방 메뉴에서 게임을 고르고 `AI와 1대1` 또는 `AI와 2대2 팀전`을 누른다. 별명을 생략하면 플레이어라는 이름으로 시작한다. 게임을 고르기 전에는 시작 버튼을 사용할 수 없다. 두 모드 모두 서버·번역·외부 AI API를 호출하지 않는다. 현재 창에서만 유지되며 새로고침하면 초기화된다. 게임 종료·재시작·다른 게임 선택·화면 이탈 때 이전 AI 타이머를 취소한다.

| 게임 | AI 1대1 | 혼자 AI 2대2 | 규칙 |
| --- | --- | --- | --- |
| 다빈치 코드 | 기존 26장 규칙 | 나+AI 대 AI+AI | [4인 분배와 자체 팀 승리](FOUR-DAVINCI.md) |
| 도미노 | 기존 Lisbeth 규칙 | 기존 혼합 팀전, p2를 AI가 담당 | [기존 도미노 안내](DOMINO-LISBETH.md) |
| 자이푸르 | 기존 2인 규칙 | 제공하지 않음 | [출판사 공식 2인 게임](https://www.spacecowboys-games.com/game/jaipur/) |
| 스플렌더 | 기존 2인 규칙 | 나+AI 대 AI+AI | [공식 4인 구성과 자체 팀 30점](FOUR-SPLENDOR.md) |
| 민화투 | 기존 2인 규칙 | 나+AI 대 AI+AI | [4인 분배와 자체 팀 정산](FOUR-MINHWATU.md) |
| 부루마블 (우리 규칙) | 기존 독립 2인 규칙 | 나+AI 대 AI+AI | [독립 도시 여행 4인 팀 변형](FOUR-MARBLE.md) |

캐치마인드와 뮤직톡톡은 기존 동작을 유지한다. 기존 온라인 2인방·로컬 좌석 전환 데모·저장된 게임 규칙도 유지한다. 새 4인 팀 모드는 한 명이 같은 창에서 AI 세 명과 플레이하는 모드이며, 온라인 네 명 초대방은 제공하지 않는다. 기존 도미노의 온라인 사람 2명 대 봇 2명은 유지된다.

## 난이도와 정보 경계

- 다빈치: 공개된 타일·내 패·실패 기록으로 합법적 숫자와 조커 배치를 계산하고, 성공 확률이 높은 타일을 선택한다. 숨겨진 조커 이동으로 옛 타일 번호를 신뢰할 수 없게 되면 해당 실패 기록은 버린다. 조커 배치는 균등하다는 가정이며 개인 습관 학습은 없다.
- 도미노: 기존 `hard` 공개 정보 추론·가상 진행 평가를 재사용한다. 사용자가 게임 설정에서 난이도를 바꿀 수 있다.
- 자이푸르: 상품의 모으기 가치, 판매 수익과 보너스 잔량, 공개 낙타 수를 비교한다. 불필요하게 같은 상품을 주고받는 AI 교환은 제외한다. 기존 2인 엔진의 규칙 계약을 변경하지 않았다.
- 스플렌더: 구매 목표의 부족 보석, 토큰 반환, 예약, 점수와 귀족 접근을 평가한다. 팀원도 자원·보너스를 합칠 수 없다.
- 민화투: 즉시 획득 점수와 개인 족보 진행을 평가한다. 4인 모드는 상대 족보 차단과 미지 더미의 기대 획득도 비교한다.
- 도시 여행: 통행료 위험·현금 예비금·건설비 대비 수익·열차 목적지·대출과 면제권을 평가한다. 4인 모드는 실제 네 좌석의 소유권과 탈락을 처리한다.

정책 함수에는 해당 좌석의 `getPlayerView` 결과만 전달한다. 팀원 숨긴 패·덱 순서·주사위 난수는 제공하지 않는다. 현재 구현은 규칙 기반 전략 AI이며 사람 상대 승률을 측정한 난이도 등급은 아니다.

## 검증과 정리

### 최신 커밋의 게임 화면 보존

이전 작업을 다시 그리는 대신 현재 메인에 있는 게임판을 재사용한다. 새 팀전의 임시 공통 카드·행동 드롭다운 화면은 제거했다.

| 확인한 커밋 | 보존한 변경 |
| --- | --- |
| [`a95d389`](https://github.com/da960822-ux/gitactions-main/commit/a95d389) | 여덟 게임의 데스크톱 화면 맞춤, 읽기 쉬운 카드·보석 비용·화투 바닥패·40칸 도시판 |
| [`8282dd0`](https://github.com/da960822-ux/gitactions-main/commit/8282dd0) | 스플렌더 카드 선택 후 포커스 복구, 화투 이미지 대체 표시와 저작자·라이선스 링크, 부루마블 행동 바로가기와 말 대체 그림 |
| [`5d9ddb7`](https://github.com/da960822-ux/gitactions-main/commit/5d9ddb7) | 게임 전환 안내·기존 게임 조작·높이가 낮은 화면에서의 스플렌더 카드 배치 |

- 2인 화면과 4인 화면을 분리한다. `FourPlayerRoom`은 세션·경로만 관리하며, 지원하지 않는 게임에는 대체 게임판을 렌더링하지 않는다. 공통 카드 목록·행동 드롭다운과 2인 화면을 감싸는 팀전 어댑터는 폐기했다.
- 스플렌더 팀전은 전용 `SplendorTeamTable`에서 네 사람의 개별 자원·팀 점수·시장·귀족·예약과 보석 그림 직접 선택을 처리한다. 2인판 전체를 마운트하지 않는다.
- 다빈치 팀전은 전용 `DaVinciTeamTable`에 내 패·팀원·두 상대를 각각 배치하고 상대 타일을 직접 선택한다. 추측은 숫자 선택 뒤 한 번 확정한다.
- 민화투 팀전은 전용 `MinhwatuTeamTable`에서 네 사람의 점수·획득패·족보와 내 손패·바닥패를 배치한다. 기존 화투 그림과 출처 표시는 보존한다.
- 부루마블 팀전은 전용 `MarbleTeamBoard`의 네 사람 자산·40칸 지도·네 말과 게임 고유 행동 영역을 사용한다. 같은 게임의 그림·말·이동 효과만 유지한다.
- 기존 사람 대전과 AI 1대1도 각 게임의 화면에서 직접 조작한다. 캐치마인드를 포함한 7개 게임에서 중복된 차례·규칙 설명을 줄이고, 규칙과 설정은 필요할 때 펼친다. 뮤직톡톡과 랜딩은 이 변경 대상에서 제외한다.

민화투와 도시 여행은 기존의 여러 단계 획득·주사위 효과가 중간 생략되지 않도록 AI 행동 간격을 각각 2800ms·2400ms로 둔다. 다른 게임은 700ms로 시작한다.

각 엔진은 여러 시드의 합법 행동·경기 종료·카드/토큰 보존·팀 정산·숨겨진 정보 차단을 검증한다. 별도 검토자는 클라이언트 타이머·화면 이탈·재시작·게임 전환 및 서버 연결이 설정된 환경에서도 AI 모드가 서버를 호출하지 않는 것을 확인한다. 전체 테스트와 프로덕션 빌드, 실제 브라우저 조작은 별도 검증으로 구분한다.

폐기한 자이푸르 4인 구현·테스트·문서는 삭제했다. 이 변경에 실험용 엔트리·임시 스크립트·스크린샷·빌드 산출물·백업 파일을 포함하지 않는다. 기존 `previewSpaceV19`와 `story/preview.css`는 현재 랜딩이 실제로 사용하므로 이름만 보고 삭제하지 않는다. 기존 규칙 버전 호환 코드와 자산 출처 기록도 유지한다.
