# 플레이 감사 이후 수정과 검증

## 황금열쇠

의미가 약한 추가 포상 카드는 제거했다. 새 방은 기존 13장과 전략 카드 3장, 총 16장이다. 기존 방의 카드 구성은 유지한다.

- 페스티벌: 자신의 도시 한 곳을 선택한다. 상대가 다음으로 그 도시에 도착할 때 통행료가 한 번 2배다.
- 정전: 상대 도시 한 곳을 선택한다. 자신이 다음으로 그 도시에 도착할 때 통행료가 한 번 절반이다.
- 통행료 면제권: 한 장을 보관하고, 통행료 지급 직전에 직접 선택해 한 번 면제한다. 자동으로 사용하지 않는다.

도시 효과는 도착 전까지 유지한다. 같은 효과를 다시 적용하면 교체하며 배율을 계속 곱하지 않는다. 두 효과가 겹치면 원래 통행료가 된다. 면제권을 쓰더라도 도착한 도시의 일회성 효과는 소모된다. 대상 도시가 없을 때의 안내, 서버의 소유권·행동·금액 검증, 사용한 면제권의 덱 복귀를 포함했다. 세 카드에는 서로 다른 실제 SVG 그림과 한국어·스페인어 설명을 연결했다.

상세: [카드 규칙](GOLDEN-KEY-EXPANSION.ko.md), [그래픽 구성](GOLDEN-KEY-CARD-ART.md).

| 자이푸르 | 시장·공급·손패·행동을 함께 볼 수 있도록 배치 개선, 기존 접이식 기록 유지, 재대결 동의 연결 | 통제 중반 상태에서 두 언어 × 두 해상도 확인 |
| 스플렌더 | 시장·은행·보관 영역 배치 개선, 기존 공개 할인 표시 유지, 소유 개발 카드 수 추가, 재대결 동의 연결 | 통제 중반 상태에서 두 언어 × 두 해상도 확인 |
| 민화투 | 잡기 선택 버튼과 손패 배치 개선, 원격의 종류별 획득 카드 행·검사 배치를 보존 | 통제 선택 상태에서 두 언어 × 두 해상도 확인 |

검사 해상도는 1366×768과 1440×900이다. 통제 상태의 화면 검사는 자연 플레이로 전략 카드나 모든 분기를 만났다는 의미가 아니다. 뮤직톡톡 원작은 수정하지 않았다.

## 실행 결과와 범위

- 원격의 민화투 획득 카드·검사·피드백 개선을 보존해 병합했다. 병합 후 최종 `npm test`: 48개 파일, 415개 테스트 통과.
- 최종 `npm run build`: TypeScript, Vite, 서버 엔진 번들 생성 통과.
- 민화투 병합 후 네이티브 브라우저 검사: 두 언어의 초기·선택·다량 획득·종료·동작 감소 상태 등 140개 검사 통과, 오류 0건. 원격 카드 배치를 덮어쓰던 세로 칸·압축 스타일은 제거했다.
- 독립 감사의 실제 플레이와 사진: [감사 기록](PLAYTEST-FINDINGS.ko.md), [게임별 PNG](playtests/README.ko.md). 이 사진은 수정 전 감사의 원본이며 수정 후 화면과 구분한다.
- 두 컨텍스트 감사는 로컬 SQL/RLS와 수동 상태 동기화로 검증했다. 운영 Supabase Auth·PostgREST·Realtime을 검증한 것은 아니다.
- 실제 기기의 오디오·물리 IME, 뮤직톡톡의 성공적인 중반 진행은 확인하지 않았다.
