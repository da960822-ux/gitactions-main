## 게시된 결과

각 이미지가 decode되면 고정된 자리에서 나타나며 본문/버튼은 기다리지 않는다. 초기 HTML과 CSS root의 어두운 배경이 일치해 React 이전과 기존 route 대기 상태도 어둡다. 새 전체 로딩 gate/스피너는 없다. 미세한 독립 깊이·창 별빛/유성·편지 전환은 얼굴 위에 장식을 그리지 않으며 사용자 정지/모션 축소를 지원한다.

승인된 부루마블33개 WebP와 조커/귀족4개 생성 초상, 기존 여섯 말과 단일 살리·술리 말, 카드 ID·비용·점수 및 private-host/env override를 보존했다. 리듬 원작 SWF는 변경하지 않았다. 모바일 게임 기능을 새로 개발하지 않았다.
