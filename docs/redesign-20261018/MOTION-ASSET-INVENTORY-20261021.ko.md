## baseline 런타임 연결과 픽셀 기여

조사 기준 commit에서 앱 진입은 [LandingWorldHost.tsx](</workspace/hero-review/src/landing/LandingWorldHost.tsx>)를 통해 [previewSpaceV19.ts](</workspace/hero-review/src/landing/cinematic/folded/previewSpaceV19.ts>)를 로드한다. 이 호출은 [folded-playhouse-lightwell.mp4](</workspace/hero-review/public/motion/folded-playhouse-lightwell.mp4>)와 [folded-playhouse-gift-edge-v18.mp4](</workspace/hero-review/public/motion/folded-playhouse-gift-edge-v18.mp4>) 두 개를 전달한다. 제작 프로젝트는 [HyperFrames](</workspace/hero-review/videos/folded-playhouse-hyperframes/>)와 [Remotion](</workspace/hero-review/videos/folded-playhouse-remotion/>)에 있다.

baseline source에서는 두 영상 모두 실제 프레임에 기여한다는 증거가 없었다. [storySurfaceV19.ts](</workspace/hero-review/src/landing/cinematic/folded/storySurfaceV19.ts>)는 `emissiveIntensity: 0`으로 표면을 만들었다. 그 baseline 런타임은 영상 texture를 해당 표면의 `emissiveMap`에 넣었지만, 표준 Three emissive 경로는 강도 0에서 기여하지 않는다. 사용자 정의 shader는 승인된 우주 이미지와 조명 결과를 `0.08 * cosmicFold`로 섞을 뿐 영상 texture를 사용하지 않았다. 표면 자체도 `progress < .27`에만 보였다. 따라서 baseline의 두 영상은 내려받아 디코드하고 map에 연결되었지만, baseline shader/material 상태상 영상 픽셀 기여는 0이었다. `surfaceVideoOwner` 진단값은 진행 구간에 따라 Remotion/HyperFrames 이름을 붙이는 의도 표기이지, 눈에 보이는 영상의 검증 증거가 아니다.

baseline source가 불러온 [chamber.glb](</workspace/hero-review/public/models/folded-chamber-r8-space-v6/chamber.glb>)도 `VERSIONED_SHARED_CHAMBER` root의 `visible=false`로 숨겨졌다. 일부 stage root는 별도 portrait rig로 옮겼다. baseline 히어로는 승인 우주 이미지를 같은 indexed sheet에 투사해 휘는 방식이고, 방 일러스트를 고정 평면으로 쓴다고 소스 주석이 명시했다. 이는 실제 3D 카메라·곡면의 존재와 별개로, 예전 접힌 방 모델 전체가 보였다는 뜻은 아니다.

## 품질·재사용 판단

- **명확한 실제 3D:** 세 Remotion intro export는 source가 Three scene을 frame별로 렌더한다. 접힌 형태와 조명이 실제 샘플 프레임에 보인다. 사진 cutout은 승인된 현재 커플 원본과 동일하다고 확인되지 않았다. 현재 제품은 이 export를 재생하지 않고 다른 scene/source로 렌더한다. 마지막/첫 포즈, crop, 색, 카메라 동일성은 아직 입증되지 않았다.
- **장식용 조명:** `folded-light-hyperframes`는 표면/히어로 전환을 보완할 추상 장식 후보였다. `lightwell`과 `gift-edge-v18`은 대용량 영화가 아닌 저대비 작은 light texture였다. baseline map 지정은 있어도 당시 material 설정 때문에 보이지 않았다. 세 export는 삭제했으며 source는 보존한다.
- **구형/대체본:** `folded-playhouse-surface`, `gift-edge-v16`, `gift-intro-remotion`의 제작 소스는 보존했다. public export는 2026-10-21 cleanup에서 삭제했다. surface는 제작 brief에서 이미 대체된 산출물이었다.
- **도구 증거:** HyperFrames 프로젝트 두 곳과 Remotion 프로젝트 두 곳 및 대응 제작 source를 보존했다. baseline 당시 export 9개가 있었으며, cleanup 뒤 현재 public export는 0개다. 각 baseline export는 이름·구성·크기/길이가 대응하는 source에 매핑되지만 export별 render record가 없어 exact render provenance는 미확인이다. export 존재는 사용자가 의도한 재사용, 최종 승인, 제품 기여, 전체 timeline의 품질 확인을 증명하지 않는다.
