# Design references

## Supplied couple design archive

The user supplied `1-yeonseok-lisbeth-codex-skill.zip` as reference material for this personal site. Its `couple-landing-design` notes informed the private-gift tone, midnight plum and rose-gold palette, expressive display typography, and desktop-first layout. The archive was used as a reference only: its `SKILL.md` and agent metadata were not copied into `.agents/`, registered as instructions, or added as runtime code.

The included couple illustration is preserved unchanged as a separate source asset. A background-removed hero cutout was generated from it and may have small image-generation changes. The rose-game atlas and dark background are separate original decorative assets. No screenshots, product copy, code, or image output from the reference archive were used beyond the included couple illustration.

## Implemented direction

The current desktop homepage gives all eight game choices a wide horizontal row as its main content. A short personal welcome uses the couple's 400px unframed portrait cutout as supporting art. Below the games, a clearly labelled static Korean/Spanish chat-translation example sits beside the bilingual letter. The static example does not accept input or represent a live chat; actual chat takes place inside game rooms. There is no photo gallery, which the user does not plan to use.

The target is desktop. Mobile CSS is only a fallback and can be refined later; do not call it fully designed or visually verified before then. The example and artwork must remain secondary to the real games, and all visible actions should lead to an implemented route or section.

This is not a public signup funnel or a product marketing page. Do not add social proof, counters, invented dates, pricing claims, testimonials, or unsupported features. The user-supplied private design archive is not an installable project skill. Do not send the couple's images to third-party services or public inspiration galleries without permission.

## Asset and motion constraints

The generated home atlas is a static 4×2 sprite sheet. Generated sprite art decorates Jaipur goods and Splendor gems. Splendor card faces map to the game's exact card signatures, and the 48 Hwatu SVGs map one-to-one to the Minhwatu engine deck; see the image-source and license limits in [`ASSETS.md`](ASSETS.md). Do not claim original-or-better fidelity to publisher artwork. CSS handles layout and restrained motion, with reduced-motion support; there is no video or HyperFrames runtime. The portrait source, cutout, generated background and game artwork, supplied-image provenance, and font licenses are documented in [`ASSETS.md`](ASSETS.md).

Project-local design and motion skill provenance, separate from the user-supplied archive, is recorded in [`SKILLS.md`](SKILLS.md).
