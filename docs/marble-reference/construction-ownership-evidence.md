조사일: 2026-10-27. 범위: 일반 한국맵, 유료 아이템/캐릭터 능력 미적용을 목표로 하는 독립 구현. **특정 과거 빌드가 확정된 완전 복원 사양은 아니다.** 당대 관찰, 최신 회고 규칙, PC를 구분한다. 미확인 상수는 임의값으로 원작이라고 주장하지 않는다.

## 2. 중요한 계약 수정

1. 건물은 단일 tier가 아니라 **종류별 보유 집합**이다. 빌라·빌딩·호텔의 독립 선택과 동시 존재를 보존한다. level만 저장하면 빌라 없이 빌딩만 지은 상태를 표현하지 못한다.
2. 일반 건설의 바퀴 제한과 랜드마크 자격을 분리한다. 특히 이미 3건물을 가진 도시를 인수하면 자신의 일반 건설 해금 부족과 무관하게 랜드마크를 지을 수 있다는 M3 예외가 있다.
3. 통행료 정산과 인수 결제는 별도 거래다. 현금 부족 매각 후 남은 돈으로 인수 가능한 M4 사례를 지원해야 한다.
4. 랜드마크의 방어는 전역 invulnerable boolean이 아니다. M2의 한국맵 blackout은 랜드마크를 포함한다.
5. 소유자 색과 지역 컬러그룹을 별도 필드로 둔다. 컬러독점용 그룹색을 소유자색으로 덮어 없애지 않는다.

V4는 **한국맵 가격표가 아니라 월드맵 UI 표본**이다.

V2 PC 부에노스아이레스는 땅 25만, 별장 10만, 빌딩 30만, 호텔 50만이 개별 체크 행이다. **PC와 모바일의 숫자 단위/방/맵이 다르므로 교차 사용 금지.**

독립 엔진 권장 입력 구조(원작 내부 코드라는 주장이 아님):

```text
CityEconomy {landCost, villaCost, buildingCost, hotelCost,
             landmarkCost, tollByBuildingMask, landmarkToll,
             acquisitionValuationPolicy, liquidationPolicy}
Quote {baseCost, discountAmount, payable, resultingToll, eligibilityReasons}
```

일반 건설 합산은 V4의 샘플에서 검증되지만 모든 건물 조합의 통행료 합산법은 확인되지 않았다. `tollByBuildingMask` lookup은 검증 전 잘못된 선형식을 박아 넣지 않기 위한 안전한 설계다.

## 5. UI 상태 계약과 픽셀 증거

### 관찰된 정지 프레임
- **V4 BUY_OPTIONS**: 제목 도시명, 닫기 X, 땅/빌라/빌딩/호텔 4카드, 아이콘·단가·선택표시, 잠금 사유, gross/discount/net/toll. 땅 필수 상태는 일반 checkbox와 다르게 표시된다.
- **V5 START_SELECT_CITY**: 중앙 지시문, 보유 도시 후보만 밝게, 비후보 배경 dim, 취소 버튼. 선택자는 START에 서 있다.
- **V1 BOARD_IDLE**: 작은 저층·중층·고층 입체 군집, 소유색 지붕, 깃발, 캐릭터 원형 받침. 컬러그룹 타일은 건물 아래 유지.
- **V3 LANDMARK_CARD**: 일반 건물 체크 목록과 다른 제목/상징물 카드. 잘린 이미지라 전체 버튼/가격/후속 상태는 알 수 없다.

### 구현 상태 전이 제안
```text
ARRIVAL_UNOWNED → BUY_OPTIONS → CONFIRM_QUOTE → COMMIT_PURCHASE → BUILD_VISUAL → TURN_RESOLVE
ARRIVAL_OPPONENT → TOLL_QUOTE → [LIQUIDATION_IF_NEEDED] → PAY_TOLL
                → ACQUISITION_OFFER → [COMMIT_ACQUISITION → BUILD_OPTIONS] → TURN_RESOLVE
ARRIVAL_START → SALARY_RESOLUTION? → START_SELECT_CITY → BUILD_OPTIONS → BUILD_VISUAL → TURN_RESOLVE
```

물음표는 START 급여의 정확한 UI 순서를 아직 관찰하지 못했다는 뜻. 인수 offer 취소/시간초과, 자금 부족 구매 버튼 상태, 기존 건물 체크 잠금 표현도 미관찰이다.

### 시각 구현 검증 목록
- villa/building/hotel 각각 식별 가능한 실루엣과 높이. 같은 칸에서 최대 세 종류 공존.
- 소유색은 모델 지붕/깃발/기단 등으로 명확히, 지역색은 보존.
- 건물과 말의 위치 슬롯을 분리하여 가려짐 방지. 같은 칸 다인 말의 정확한 원작 배치는 미확인.
- 랜드마크는 독특한 큰 실루엣. 기존 건물 제거 vs 보존의 전환 프레임 미확인.
- 실제 3D 자산을 작고 평평한 배지로만 대신하지 않기.
- 배치/착지 모션, 파티클, 카메라, 음성, duration, easing은 영상 확인 전 원작 수치로 기재하지 않기.

## 6. PC 차이 — 목표 규칙에서 격리

P1 공식은 최초 별장만, 출발지 통과에 따라 빌딩·호텔을 해금하고 세 건물이 있는 도시 재도착으로 랜드마크를 허용한다. 도시 클릭 시 가격과 통행료가 보인다. 관광지에는 일반 건설이 없고 랜드마크는 인수 불가다. '모든 공격 방어' 표현이 있지만 모바일 한국맵 M2 blackout 예외 때문에 공통 룰로 승격하면 안 된다. P1 정확한 바퀴 규칙은 한국맵 전용을 명시하지 않으므로 모바일 한국맵 초기 두 건물 제한을 덮어쓸 수 없다.
