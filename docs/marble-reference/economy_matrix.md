## Explicitly unresolved engine requirements
- Per-city true base tolls from game UI at no boosts, matched year/class/map; calculator-derived below is a hypothesis, not ground truth.
- Exact Korean economy/business salary; class scaling across all charges; version migrations.
- Loan eligibility, use-limit vs ticket inventory, amount, extra bonus, repayment, mandatory auto decision, unavailable loan flow.
- Voluntary vs shortage liquidation, sale basis for acquired/discounted/destroyed buildings, landmark salvage, rounding, selection order, timeout auto-selection.
- Partial creditor payment on bankruptcy; tile destruction vs ownership transfer; whether debts to bank differ; team survival/elimination/inheritance.
- Total-asset valuation formula and tie breaks; team wealth aggregation vs individual leader.
- Festival eligible population and selection weights; Olympic fee/migration state, boost composition order, caps; tax zero assets and cost basis.
- Currency integer precision, rounding each component vs final sum, display rounding, minimum charge.
