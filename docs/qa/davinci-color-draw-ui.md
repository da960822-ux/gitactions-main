# 다빈치코드 색 선택 및 PC 화면 검수

기준: GitHub `main`의 다빈치코드만 수정한 `qa/davinci-color-draw-ui` 브랜치. 운영 Site v43과 동일하다고 가정하지 않았다. 2026-10-27에 로컬 Vite 앱의 실제 2인/4인 AI 방을 Chromium에서 확인했다. 모바일, 운영 배포, 다른 게임은 범위 밖이다.

공식 근거: [코리아보드게임즈의 다빈치 코드 게임 설명](https://www.koreaboardgames.com/magazine/menuDetail?boardCd=contents&postNo=18). 흑백 0~11 및 색별 조커 1장, 원하는 색의 타일을 전략적으로 뽑는 점, 조커의 자유로운 배치, 뽑은 뒤 추리, 정답 뒤 계속/멈춤, 오답 뒤 이번에 뽑은 타일 공개를 확인했다. **특정 색이 소진되면 다른 색만 선택하고, 모두 소진되면 뽑기 없이 추리하는 처리는 공식 설명의 직접 문구가 아니라 물리적 더미와 기존 게임 흐름에서 도출한 구현 판단이다.** 4인 2대2는 이 저장소의 하우스 규칙이다.

검증 명령: `npm test`는 **117개 파일, 1027개 테스트 통과**. `npm run build` 통과. 이후 추가한 AI 색 선택 단위 테스트는 다빈치 관련 테스트를 다시 실행해 확인했다. 로컬 Chromium 페이지 오류는 관찰되지 않았다. 스크린샷은 브라우저에서 포착한 PNG를 WebP로 압축한 것이다.
