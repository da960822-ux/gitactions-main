The official PC edition has villa/building/hotel/landmark and different unlock rules. This project keeps its existing house/apartment/landmark tiers and economy. Images are QA fixtures, not a deployed site screenshot.

PC observations: at 1280 × 800 the 2p board measures 1256 × 618 and the 4p board 1248 × 620; all start, built and exact-Start build-choice fixtures fit a document height of 800. At 1440 × 900 and 1847 × 872, all three scenarios also fit the viewport. Selected-city overlays remain within each viewport; the 2p ledger scrolls inside its overlay. Pawns measure 32 × 39 px in all captured modes. `capture-motion.mjs` and `motion.json` record actual browser clicks: in both modes dice roll, pawn stepping, money flight and construction animation were observed; a sample roll moved p1 from tile 0 to 6 and paid 100, and building reduced cash by 50. An exact-Start selection upgraded only the chosen city from level 2 to 3 and consumed the build chance. The motion PNGs show the in-progress frames. The 4p uses its status rail rather than the 2p event theater.

Verification: `npx vitest run --hookTimeout 30000 --maxWorkers 4` passed 117 files / 1,029 tests; `npm run build` passed. An initial unrestricted parallel full run exceeded the default 10-second PGlite setup timeout in three unrelated database suites; those 22 tests passed on the bounded rerun. No production deployment was made.
