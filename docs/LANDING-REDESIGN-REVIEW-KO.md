## 언어 적용 확인

랜딩은 `dos-language`에 KO/ES를 저장하고 ES일 때 문서 언어는 `es-DO`다. 같은 출처의 기존 `/play`로 직접 방문했을 때 스페인어 `Crear partida`를 실제 브라우저에서 확인했다. 랜딩에 게임 연결 버튼을 추가하지 않았다. 다른 도메인·포트 간에는 로컬 저장소가 공유되지 않는다.

기존 게임방은 참여자마다 언어를 저장한다. 이미 참여한 방에서는 해당 참여자의 저장된 언어가 우선한다. 한 사람의 ES 선택이 상대의 KO 화면을 강제 변경하지 않는다.

리듬타파 제외 7개 게임을 실제 엔진 초기 상태로 KO/ES 서버 렌더링했다(`language-review.json`). 다빈치·도미노·자이푸르·스플렌더·민화투·부루마블의 초기 ES 표시 문구에서는 한글 잔여 문구가 없었다. 캐치마인드 6개 주제·선택 단어는 사용자 언어로 표시되고 KO/ES 정답을 받는다. ES의 사용자 단어 설정에 남은 `한국어|Español`은 두 언어 입력 형식을 설명하는 표기다. 모든 진행·종료 상태의 전 문장을 재검수한 것은 아니다.

캐치마인드 채팅 번역은 기존 서비스 설정과 번역 한도가 있을 때 동작한다. 서비스 미설정·한도 도달 시 원문 표시이며, 이번 작업에서 외부 번역 서비스를 호출하거나 설정하지 않았다.

## 검증과 보존

- 최종 전체 테스트: 48개 파일, 399개 테스트 통과. 하트 표면의 유한 값·닫힌 메시 검증 포함.
- TypeScript·독립 미리보기 빌드와 기존 앱 빌드 통과.
- 기존 홈·게임의 JS/CSS 8개 파일 SHA-256이 기준 브랜치와 동일(`main-bundle-comparison.json`). 실제 게임 소스 변경 없음.
- 실제 Chromium: 8개 모델 선택, 편지 반복 열기·닫기·재개봉, Escape 후 실링 포커스 복귀, 닫힌 편지 inert, KO/ES 재로딩 저장, 움직임 축소, 390/360px 가로 넘침·종이 너비 확인.
- 편지 가림과 닫힌 disabled 버튼으로 포커스를 돌리던 문제를 실제 검수 중 수정. 모션은 경과 시간에 맞춰 전환하며, 움직임 축소 시 즉시 선택·개봉한다.
- 이전 소스와 빌드 백업은 전달 폴더 `backup/`에 보존.

## 판단의 한계와 남은 개선

이 결과는 시각 승인을 받은 최종 디자인이 아니라 검토용 미리보기다. 오브젝트는 원본 절차형 입체 미니어처이며 전문 DCC 제작품·실물 스캔이라고 주장하지 않는다. 작은 배경 오브젝트는 선택해야 충분히 읽힌다. 한국어는 시스템 글꼴에 따라 모양이 달라질 수 있다. 작은 모바일에서는 본문과 하트를 순서대로 보여주며 스크롤이 필요하다.

녹화는 소프트웨어 WebGL 환경의 실제 브라우저 입력·화면이다. 포인터 표식 외의 연출 합성은 없고, MP4 변환 시 모바일 원래 비율을 유지한다. 영상의 프레임 속도는 실사용 GPU 성능의 측정값이 아니다. 모바일 게임 화면, 실기기 iOS/Safari, 서비스 연결 플레이, 리듬타파는 이번 범위에서 검사하지 않았다.

FLOS·Lusion 정적 스크린샷을 확인한 부모 스레드의 관찰을 조명·깊이 기준으로 사용했다. 이 환경은 해당 외부 이미지 접근이 403이었으므로 직접 보았다고 주장하지 않는다. 원본 Lusion 모션·소스는 획득하지 않았다. [Motion의 3D 변환 문서](https://motion.dev/docs/3d-transforms#building-a-card-flip)는 perspective/preserve-3d/backface 원리의 참고이며 외부 봉투 코드를 복사하지 않았다.
