# 민화투 화면

- [한국어 게임방](game-room-ko.png): 실제 로컬 게임방의 초기 플레이 화면.
- [스페인어 게임방](game-room-es.png): 같은 Room 구성의 스페인어 초기 플레이 화면.
- [고도리 연출](godori-test.png): 실제 엔진과 화면 컴포넌트에 연결된 고도리 연출. 점수와 패 배치는 검증용 시나리오이며 실제 경기 기록이 아니다.

캡처는 2026-10-11 민화투 고도화 버전이다. 초기 게임방 이미지는 1440×900 Chromium에서 촬영한 실제 Room이며 온라인 두 기기 검수 이미지가 아니다. 이미지가 전달되지 않는 채팅 환경에서도 GitHub 파일 화면에서 확인할 수 있도록 보관한다. 브라우저 검사 전체 임시 산출물은 계속 Git에서 제외한다.

2026-10-11 재수정: 게임방 초기 이미지를 가로 획득 영역 버전으로 교체했다. [한국어 획득패 배치](capture-bank-ko.png) / [스페인어 획득패 배치](capture-bank-es.png)는32장 적재·빈 바닥의 배치 검증 시나리오이며 실제 플레이 기록이 아니다. 대표패 요약/클릭 검사 창 없이 전면을 모두 펼친다. [한국어 그림 설명](guide-ko.png) / [스페인어 그림 설명](guide-es.png)은 실제 Room 하단 설명이다. 기존 고도리 캡처는 이전 배치의 연출 자료이며 이번 최종 배치가 아니다.

[양측48장 정리 한국어](all-captures-ko.png) / [스페인어](all-captures-es.png)는 엔진 규격을 보존한 종료 fixture를 실제 컴포넌트에 표시한 검증용 화면이다. 두 좌석 각24장, 광5/열끗9/띠10/피24의 총48개 고유 얼굴을 모두 표시한다. 실제 온라인 경기 캡처는 아니다.
