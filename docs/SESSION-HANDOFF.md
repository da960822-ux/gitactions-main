# 작업 인계 — 2026-10-24

## 최신 변경: 방 흐름과 부루마블

- [방 흐름](ROOM-FLOW.md): 게임 선택 후 친구/AI로 바로 시작한다. 별명은 선택이며 수동 초대 코드 입력은 제거했다. 내부 UUID와 비공개 링크는 유지한다. 명시적으로 입장한 신규 p2만 시작 전 초대 게임에 한 번 동의하며, 기존 회원·재접속·진행 중 판에는 자동 동의하지 않는다. 선택 요청은 버전 고정으로 오래된 요청 재전송을 막는다.
- 같은 게임 재시작 시 도미노 모드·난이도·목표와 캐치마인드 설정을 유지한다. AI는 즉시 새 판, 사람 온라인은 상대 동의를 유지한다. 새 방을 반복 생성할 때 이전 방 버전과 상태가 유입되던 문제도 수정했다.
- 부루마블 새 판은 `propertyRulesVersion: 1`로 인수·최종 단계 보호·개인 색상 독점 2배·더블과 3연속 무인도·채무 도시 매각을 적용한다. 2인/4인 모두 동일한 금액 계산을 사용하며 이전 저장판은 원래 규칙을 유지한다. [공식 규칙 비교와 차이](FOUR-MARBLE.md).
- 전용 그림 도움말은 한국어·도미니카 스페인어로 제공한다. 한국어는 광주, 스페인어는 산토도밍고의 실제 계산값으로 단계표를 그린다. 새 인수 보호/더블 그림 2개와 기존 도시·건물·황금카드 자산을 사용한다. 새 자산 출처·크기·SHA256은 `public/images/marble/guides/manifest.json`에 기록했다.
- 소유 색은 2인 로즈골드/민트, 4인 팀별 같은 계열의 두 명암과 좌석 표식으로 구분한다. 도시 독점 그룹 색과 소유자 표시는 서로 분리한다.
- 독립 검토자는 황금카드 16종을 양 엔진에 직접 적용하고 AI 대전 300판의 합법 행동·완주를 확인했다. 도움말 한국어/스페인어 × 2인/4인 네 경로의 실제 이미지 로드·금액·16종 안내·넘침도 별도로 검수했다. 최종 전체 108개 파일·958개 테스트와 프로덕션 빌드가 통과했다. 소유색·숫자는 한국어/스페인어 × 2인/4인 × 1366×768/1440×900의 8조건에서 확인했고 가격 잘림·소유번호 겹침은 없었다.
- 운영 Site/Edge 배포, 실제 두 기기의 온라인 초대 및 도미니카 원어민 사람 감수는 수행하지 않았다. 기존 Edge 런타임 번들은 빌드로 갱신하며, 새 임시 검수 스크립트·스크린샷·원본 생성 PNG·dist는 커밋하지 않는다.

## 앞선 변경: 혼자 AI 모드

- [AI 모드 안내](AI-MODES.md): 6개 보드게임 1대1, 자이푸르 제외 5개 2대2. 공식 2인 전용 자이푸르는 2인으로 유지한다. 캐치마인드는 UI만 다듬고 AI를 추가하지 않았다. 뮤직톡톡과 기존 온라인 방 규칙은 유지했다.
- 새 4인 팀 모드는 현재 창의 사람 1명+AI 3명이다. 도미노는 기존 팀 엔진을 재사용하며, 다른 네 게임의 팀 승리·정산은 출처가 명시된 자체 변형이다. AI는 팀원 비공개 패도 보지 않는다. 서버와 외부 AI API 없이 동작하고 새로고침 시 초기화된다.
- 게임별·인원별 화면: 공통 게임판과 2인판을 감싸는 팀전 어댑터를 제거했다. 네 게임의 4인판은 각각 독립 화면이고 방 라우터는 세션만 관리한다. 스플렌더 내 보석은 하단 전용 영역으로 구분한다. [UX 검수와 참고 기록](GAME-UX-REVIEW-2026-10-24.md).
- 앞선 AI·게임화면 통합 검증: 104개 파일·895개 테스트와 프로덕션 빌드 통과. 별도 검토자가 관련 159개 테스트, 네 4인 화면의 실제 사람 행동·1366×768 화면 배치·비공개 정보 경계를 확인했다. 구현 담당자는 1440×900 및 조커 배치·초과 반환·획득 후 밀집 화면·말 선택·구매·건설도 별도로 검증했다. 기존 엔진의 2인 200판·4인 160판 합법 행동과 종료 검증도 유지한다.
- 폐기한 자이푸르 4인 코드·테스트·문서는 삭제했다. 새 임시 스크립트·스크린샷·빌드 산출물은 Git 변경에 포함하지 않는다. 현재 랜딩이 사용하는 preview 이름의 파일과 기존 규칙 호환 코드는 유지한다.
- 위 검증은 로컬 빌드와 브라우저 기준이며 기존 비공개 Site에 새 배포를 수행한 기록은 아니다. 사람 상대 난이도 승률은 측정하지 않았다.

Production revision 19가 source `63ac3a11d410141971cbd0c617d226731157c709`로 배포되었으며, Site는 owner-only, user 1명/external 0명, env revision 1입니다. 연결된 artifact는 508개 파일, 149,029,026 bytes입니다. 실제 배포 주소에서 온라인 방/캐치마인드/양방향 번역, 상대 Chrome의 9획 해파리 동기화, 스페인어 정답과 양측 점수가 모두 통과했습니다. 다음 배포에서도 등록된 Site의 `.openai/hosting.json` ID와 audience를 유지합니다. Cloudflare Pages는 별도 구성 호스트입니다.

게임 규칙, 개인 손패/RLS 보호, 번역의 원문 보존 및 7일 보관, 피드백 게시물 보관 정책을 유지합니다. 홈과 게임 이미지의 자산 출처는 `docs/ASSETS.md`를 따르세요. 장미 배경·아틀라스는 정적 장식 이미지이며 라이브 3D가 아닙니다. `public/` 자산은 Site에 접근 가능한 사용자에게 URL로 제공되므로 현재 소유자 전용 접근 정책을 바꾸지 않습니다.

뮤직톡톡은 원본 SWF와 Ruffle을 사용합니다. 전체 게임플레이·오디오·동반 SWF 동작과 SWF 재배포 권리는 확인되지 않았습니다. 출시 범위나 권리 상태를 임의로 확대해 표현하지 말고 [리듬게임 안내](RHYTHM.md)를 참조하세요.
