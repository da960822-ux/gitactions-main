# Marble 폴리시 계약 및 QA

## 핵심 경제 규칙

- 40칸, 도시 부동산 24곳, 황금열쇠 6칸. 두 주사위 합만큼 이동하고 출발 통과 시 200을 받는다. 빈 부동산은 매입하거나 지나간다. 상대 임대료는 자동 납부한다.
- 현대 보드에서는 소유한 도시마다 별장(Villa) → 빌딩(Edificio) → 랜드마크(Monumento)를 각 100에 건설할 수 있다. 색상 세트 완성이 건설 조건은 아니다. 단계별 임대료 배율은 기본, 2배, 4배, 8배다. 세 번째 단계의 `landmark` 표시는 별도 임대료 배율을 만들지 않고 8배 규칙을 따른다.
- 기본 대출은 한 번에 300을 빌리고 부채 330을 기록한다. 자기 차례의 일반 단계에서 미리 빌릴 수 있고, 한 건이 남아 있으면 추가 대출은 허용하지 않는다. 이자 누적이나 만기일은 없다. 자기 차례의 일반 행동 단계에서 330 전액을 상환할 수 있다. 총자산 계산은 현금·부동산·건설비 합에서 부채를 뺀다.
- 지불 위기 때 현금이 부족하면, 현금 + 새 대출 300으로 해당 지불액을 낼 수 있을 때 대출 선택지를 보여 준다. 대출은 선택이다. 파산 양보도 별도 선택으로 제공한다. 상대 좌석의 독점 부담금이면 그 플레이어를 잠시 활성 채무자로 전환해 결제한 뒤 원래 카드 드로어의 차례로 돌린다.
- 황금열쇠의 건물 수리 카드는 보유 부동산의 건설 단계 수 합계마다 40을 낸다(별장 1단계, 빌딩 2단계, 랜드마크 3단계). 도시세 100, 기금 납부 150, 기금 칸에서 누적액 수령. 무인도에서는 세 차례를 쉬며 쌍을 시도하거나 100 또는 탈출권으로 나온다. 역은 다음 자기 차례에 100으로 부동산 이동 또는 건너뛰기, 카드 열차표는 무료다. 120턴 뒤 부채를 뺀 총자산으로 승자를 정한다.

## 황금열쇠 13장

| 카드 | 효과 |
| --- | --- |
| 동네 축제 | +150 |
| 작은 복권 당첨 | +200 |
| 임대료 환급 | +80 |
| 여행 경비 | −100 |
| 건물 수리 | 보유 건설 단계마다 −40 (별장 40, 빌딩 80, 랜드마크 120) |
| 산토도밍고 방문 | 이동 후 정상 착지 규칙 적용 |
| 출발점으로 이동 | 출발로 이동, +200 |
| 세 칸 뒤로 | 3칸 후퇴, 출발 보너스 없음 |
| 무인도로 이동 | 이동 후 세 차례 대기 |
| 탈출권 | 무인도에서 쓸 권리 1개 보관 |
| 무료 열차표 | 운임 없이 부동산 선택 이동 |
| 도시 배당금 | 보유 부동산마다 +30 |
| 독점 경고 | 완성 색상 그룹 수가 많은 사람이 은행에 그룹당 100, 최대 300 납부. 동률은 카드를 뽑은 사람, 완성 그룹이 없으면 납부 없음. |

덱은 섞어 순환하고 공개 이벤트 카드만 플레이어 뷰에 노출한다. 덱 순서와 난수 상태는 비공개다. 이벤트 이력은 최근 40개를 유지하고, 접을 수 있는 최근 기록은 최신 5개를 보여 준다. 독점 경고 카드 자체는 드로어의 공개 카드로 남긴다. `cashDelta`는 공개 카드 드로어의 현금 변화이고, 액션 기록의 `moneyDelta`는 실제 지급자/수령자의 부호 있는 변화다.

## 이벤트 표시

| 동작 | 이벤트 영역 표시 | 금액 표시 |
| --- | --- | --- |
| 주사위·도착·이동·카드·무인도·열차 | 순서가 있는 한국어/스페인어 제목과 설명, 플레이어와 이동 맥락 | 금전 변동이 없으면 숫자를 만들지 않음 |
| 매입·건설·임대료·세금·보너스·대출·상환 | 행위별 아이콘, 실제 송금 방향과 카드/도시 설명 | `moneyDelta` 실제 정산만 부호를 붙여 표시 |
| 파산 위기·독점 부담금 평가 | 청구/부담금 예상 금액을 ‘지급 필요’로 표시 | 평가 단계는 차감 애니메이션 없음; 정산 기록에서 실제 변동 표시 |
| 파산·승리 | 종료 원인과 승패, 결과 패널 | 최종 결과의 현금/순자산 점수 |

새 액션 이벤트는 서버 확정 뷰에 도착했을 때 순서대로 잠시 보여 주고, 첫 렌더/좌석 변경에서는 지난 일을 새로 재생하지 않는다. 동작은 640ms 단위로 이어지고, `prefers-reduced-motion`에서는 최신 상태만 보여 준다. 이력은 40개 보관, 최근 5개를 열어 볼 수 있다.

## UI·모션 계약

- KO/ES 보드에 현금, 대출 차감 후 순자산, 현재 행동과 청구 금액을 표시한다. 대출은 300/상환 330, 추가 대출 불가, 파산 양보의 결과를 선택 전에 알린다.
- 시작 좌석의 말 고르기는 보드 중앙 3×2 영역에 6개 이름과 그림으로 보인다. 상대가 쓰는 말은 비활성화하고, 상대 차례에는 선택기를 숨긴다. 첫 주사위 뒤에는 말 선택을 잠근다.
- 주사위 펄스, 이동 토큰, 카드·열차 경로, 소유지 강조는 서버 확정 뷰 변화에서만 재생한다. `prefers-reduced-motion`에서는 애니메이션을 끄되 최종 위치/상태를 표시한다. 사운드는 공유 컨트롤러에 맡긴다.

## QA 포인트

- KO/ES에서 40칸·24도시·도시명·현금·부채 차감 후 자산·현재 차례 및 법적 행동이 맞는지 확인한다. 문서 가로 넘침, 잘못된 이미지, 비공개 상태 노출이 없어야 한다.
- 빈 부동산 매입/거절, 상대 임대료, 별장·빌딩·랜드마크 3단계 건설과 1/2/4/8배 임대료, `landmark` 표시와 8배 일치, 단계당 40 수리비, 세금·기금, 13개 카드 효과와 공개 설명을 확인한다.
- 대출·위기 처리: 일반 자기 단계에서 300 대출 및 330 부채 기록, 기존 대출이 있으면 추가 대출 차단, 일반 자기 단계에서 330 전액 상환, 단편 상환 불가. 위기 때는 현금+300이 지불액을 충족할 때만 대출 선택, 파산 양보, 총자산에서 부채 차감.
- 상대에게 지급하는 임대료/독점 경고에서 부족액을 상대가 먼저 정산할 때 채무자에게 제어가 넘어가고, 정산 후 원래 플레이어의 차례·진행이 복원되는지 확인한다. 은행에 지급하는 독점 경고는 그룹 1~3개, 양측 동률, 그룹 없음, 상대 그룹 수가 더 많은 경우를 확인한다.
- 산토도밍고 착지, 출발 보너스/후퇴, 무인도 성공·실패/유료 탈출/권리 사용, 유료·무료 열차 목적지 및 건너뛰기, 120턴 자산 판정을 확인한다.
- 이벤트 카드·상태 이력은 공개 정보만 담고, 덱 순서/난수와 상대의 비공개 데이터는 노출하지 않는다.

## 검증 상태

최신 저장소 검증: 루트 실행 전체 테스트 214/214 통과, 프로덕션 빌드 통과. 2026-10-10 native Chromium 캡처는 `output/playwright/game-polish/marble-premium-final-capture.json`과 `/mnt/data/marble-premium-{ko,es}.png`에 있다. 두 언어 모두 40칸, 수평 overflow 없음, 깨진 이미지 없음, 브라우저 오류 없음. KO 활성 좌석은 보드 중앙에서 6개 말 중 5개 선택/상대 말 1개 비활성을 확인했고, ES 상대 좌석은 대기 상태에서 선택기가 숨겨짐을 확인했다. 전체 보드 캡처는 `/mnt/data/marble-premium-board-{ko,es}.png`다.

별도 2인 HTTP 초대방 플레이에서는 두 좌석의 주사위·구매·건설·턴 종료 각 2회와 대출·상환을 확인했다(`marble-native-qa.json`). 로컬 fixture에는 Realtime이 없어 상대 화면은 새로고침으로 갱신했다.

실제 `marbleEngine.applyAction`으로 상태를 전환하는 독립 브라우저 검사도 23/23 통과했다(`marble-deterministic-qa.json`). 독점 경고의 상대 채무자 전환과 차례 복귀, 대출 +300·실제 부담금 −200의 1회 처리, 통행료 −15 송금, 열차 목적지·무인도 연출, 파산 확인과 승패, 새 승리 애니메이션, 모션 감소 설정, 종료 화면 재진입 시 과거 승리 재생 방지, 타이머 정리를 확인했다. 특수 상황의 시작 상태를 지정한 검사이며 자연 발생한 온라인 게임의 증거는 아니다.

운영 Supabase Realtime과 실제 오디오 기기의 효과음 청취는 검증하지 않았다. 기존 저장방은 저장된 규칙을 유지하고 신규 방에 새 대출·독점 경고 규칙을 적용한다.
