# 방 입장과 재시작

게임을 고른 뒤 `친구와 플레이`를 누르면 방을 만든다. 별명은 선택 사항이며, 초대 코드를 입력하는 별도 과정은 제공하지 않는다. 방 주소의 내부 UUID는 비공개 링크와 서버 검증에 필요하므로 유지한다. 최근 일반 방은 게임 메뉴에서 다시 열 수 있다.

호스트는 링크를 공유하고, 초대받은 사람은 언어를 고른 뒤 `초대한 게임에 참여`를 한 번 누른다. 신규 p2이고 아직 시작 전이면 초대한 게임 선택에 동의해 시작한다. 이미 참여한 회원의 재접속이나 진행 중인 게임에는 자동 동의하지 않는다. 요청한 버전이 달라지면 이전 선택을 재전송하지 않고 현재 게임을 확인하도록 안내한다. 클립보드 사용이 막히면 복사할 링크를 직접 선택해 준다.

AI는 게임 선택 후 `AI와 1대1` 또는 지원 게임의 `AI와 2대2 팀전`으로 바로 시작한다. 자이푸르는 2인 전용이며 캐치마인드·뮤직톡톡에는 AI가 없다. AI 진행은 새로고침 시 초기화된다. 서비스 미설정 데모는 같은 브라우저의 두 좌석으로 바로 시작하며 기기 간 초대가 아니다.

완료된 게임의 재시작은 게임판 상단에 놓아 스크롤 없이 찾을 수 있다. AI 게임은 `다시 하기` 한 번으로 시작한다. 온라인 사람 대전은 상대 동의가 필요하며 요청한 사람에게 대기 상태를 표시한다. 실패한 요청은 다시 시도할 수 있다. 같은 게임의 재시작은 도미노 모드·목표·난이도와 캐치마인드 설정을 유지하면서 패·점수·경기 진행을 초기화한다.

새 방 생성 때 이전 방의 버전과 상태를 초기화하고, 시작·동의 요청에는 버전을 고정한다. 공개 방 목록, 신규 계정 절차, 암호 입력과 추가 준비 화면은 만들지 않는다.

실제 Chromium에서 한국어 1366×768·스페인어 390×844의 별명 없는 시작, AI 진입, 초대 화면, 클립보드 실패 대체 동작을 확인했다. 온라인 입장·서버 합의·재시작 설정과 오래된 요청 차단은 별도 클라이언트/Edge 테스트로 검증한다. 실제 운영 서비스의 두 기기 온라인 초대와 배포 검증은 수행하지 않았다.
