# 부루마블: 손으로 집어 옮기는 여행 보드

현재 검토 화면(`/workspace/onboarding/review/upgraded-marble.png`)은 도시가 작은 글자 목록으로 보이고, 중앙에는 말 선택 카드가 크게 자리한다. 플레이어가 처음 보는 것은 세계 여행판보다 조작 패널이다. 기존 24개 도시 SVG와 여섯 동물·캐릭터 말의 실제 일러스트를 살리고, 중앙 지도·입체 건물·도시 소유권 증서를 더해 실물 보드의 공간 관계를 만든다. 색상 변경만으로 해결하지 않는다.

## 고정 제작 규격

React/DOM의 현 구조를 유지하는 2.5D 일러스트 방식이다. WebGL/3D 엔진이나 새 런타임 의존성은 필요 없다. 시점은 위에서 내려다보는 정투영 사선, 광원은 왼쪽 위, 윤곽선은 짙은 청회색이다. 지붕과 앞면은 밝게, 오른쪽 벽은 어둡게 한다. 종이·목재·석재·유리를 면과 물체 형태로 표현한다. 기능 문자·가격·통행료·소유자·도시 이름은 모두 DOM에 둔다. 깃발이나 숫자는 일러스트에 굽지 않는다.

## 도시 축소와 타일 밀도

도시 SVG는 192×192 투명 캔버스이며 주요 물체가 약 x20–171, y22–185에 들어간다. 48×32에 `contain`하면 물체가 지나치게 작아지므로, 48px 폭으로 표시하고 아래 지면 끝만 제한적으로 가리거나 152×152 관심 영역을 사용한다. 랜드마크 꼭대기를 자르면 안 된다. 보조 건물 창문은 상세 그림용 장식이며 작은 타일에서 읽힐 필요가 없다. 타일에서는 랜드마크 실루엣 하나, 도시명 두 줄 이하, 도시군 띠, 소유권 마크만 남긴다. 기존 깃발·칸 번호·상태 글자와 큰 아이콘을 같은 면에 겹쳐 넣지 않는다. 상태와 가격은 선택 카드에서 읽는다.

## 새 건물과 증서의 통합 계약

세 건물은 모두 `viewBox="0 0 128 128"`, 투명 바탕, 바닥 기준점 `(64,122)`이다. 1단계는 지붕이 넓고 낮으며, 2단계는 곧게 높은 건물, 3단계는 가장 높은 첨탑과 넓은 계단 받침이다. 별도 건설 배지는 도시 그림 오른쪽 아래에 놓아 도시에 건물을 덮어씌우지 않는다. DOM 건설 단계 문구와 접근성 이름을 병행한다.

증서는 `viewBox="0 0 240 336"`이다. 그림창은 `(21,55,192,120)`. 제목 안전 영역은 `(40,16,156,30)`, 가격/매입 정보는 `(40,196,156,45)`, 통행료/건설 정보는 `(40,259,125,42)`다. 원본 비율을 유지하며 프레임 위에 도시 그림과 DOM을 겹친다. 프레임에는 텍스트, 가격, 소유자, 게임 상태가 없다. 도시 카드는 선택 도시와 보유 도시 패널에 같은 자산을 쓴다.

## 제작·검수 순서

1. 기존 파리·산토도밍고 도시와 여우 말을 기준으로 가족의 시점/광원을 고정한다. 선택권 위임에 따라 이 방향으로 제작한다.
2. 중앙 지도와 새 건물/증서를 실제 이미지 파일로 제작한다. 그래디언트 배경이나 문자 장식으로 대체하지 않는다.
3. 도시 24개는 기존 SVG를 재사용하고, 선택 도시 증서에는 큰 도시 그림을 넣는다. 판 위 도시의 크기와 읽기 밀도를 통합 단계에서 조정한다.
4. 새로운 4개 SVG는 XML 파싱, 정확한 viewBox, 외부 참조·스크립트·베이크된 문자 부재를 검사한다. 24/32/64px 건물과 180px 증서를 접촉 시트로 확인한다.
5. 실제 데스크톱 게임 화면에서 지도 노출, 두 말 겹침, 구매 전후 증서, 1→2→3 건설의 구별을 검사한다. 기존 모바일 display gate를 유지하며 모바일 게임판 입장을 새로 구현하지 않는다. UI 통합 담당이 최종 화면 검수를 수행한다.

출처·크기·용도·검수 상태는 `docs/marble-physical-assets.json`, 도시별 출처와 타일 인덱스는 `public/images/marble/cities/manifest.json`에 기록한다. 새 네 SVG는 외부 그림을 사용하지 않은 프로젝트용 직접 작성 벡터다. 신규 실제 그래픽은 약 4.4KB이며 기존 도시 원본이나 아틀라스는 바꾸지 않는다.
