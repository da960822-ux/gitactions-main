# 모두의마블 공개 자료 기반 재구현 조사 현황

2026-10-27. 이 문서는 완료 선언이 아니다. 최신 사용자 요구는 캐시 아이템/캐릭터 특수능력을 제외하고 규칙·UI·모션·효과를 세부적으로 대조하는 것이다. 공개 자료만 사용하며 APK 추출/인증 우회/비공개 서비스 분석은 수행하지 않는다.

## 기준과 출처 원칙
- 우선 기준: 한국 모바일 초기 한국맵의 일반 플레이. PC 및 LINE, 다른 맵 자료는 별도 표기한다.
- 사용자 승인: 독립 빌라/빌딩/호텔 + 랜드마크, 체크 선택 후 한 번에 확정, 네 방향 동일 타일 크기, 중앙 임의 '내 도시' 패널 제거.
- 임의 비용 배율을 원작 값이라 부르지 않는다. 미검증 값은 배포하지 않는다.
- 자료 신뢰도: 공식 시점별 문서 > 실제 인게임 캡처/영상 > 당시 계산기·공략 > 후대 위키. 차이를 숨기지 않는다.

## 기존 구현 감사에서 발견한 결함
4인 열차 거절 누락; 기금/탈출/운임/상금 거래 기록 누락; 소유권 변화 후 임대료 미리보기 오류; 여행 운임·도착 통행료 미리보기 누락; 턴 경계 뒤 이전 거래 재노출; 말 도착 전 돈 이동; 실제 적용 임대료와 기본 임대료 혼동; 매각 결과 미리보기 부족; 카드 대상 없을 때 안내 누락; 무인도 남은 횟수 누락; 보관 카드/팀 점수 노출 부족; 게임 변경 확인 누락; 스페인어 급여 및 인수 안내 불일치. 이 항목들은 완료 여부를 개별 테스트와 실제 화면으로 검증해야 한다.

## 배포 차단 조건
1. 새32 경제는 원본 XLS 수식으로 분리되었고 미수록 조합은 추론으로 표기했다. 기존40 신규 게임은 건설v1로 유지해 잠정독립비용을 활성화하지 않는다.
2. 원작32칸 한국맵과18도시/5관광지 순서는 확인했고 연구 전용 프로필을 만들었다. 사용 가능한 새 규칙판으로는 아직 활성화하지 않았다.
3. 실제 PC 화면에서 건물/말/도시명 가림과 좁은 타일 문제 검수 중.
4. 전체 규칙의 버전별 충돌과 예외 대조 미완. 감옥/기차/엑스포 요금과 일부 확률의 명시적 재구성 허용 여부를 사용자에게 질문했으며 아직 답이 없다.
5. 최종 통합 테스트·실제 플레이·온라인 엔진 동기화 미검증.

기존 배포는 v49이다. 새 32칸 작업은 미배포이며 '원작과 동일' 또는 '전체 완료'로 보고하면 안 된다.

## 12:10 통합 진행 메모
- 우선 오류 수정 배포 후보: 황금열쇠 명시적 설명/누적 확인, 이미 확인한 카드 영수증 재등장 제거, 지연 결제 상태 연결, 인수 후 기존 완성건물 랜드마크 예외, 판 프레임/말/도착 표시, 구매창 필수 버튼 무스크롤, 결과 모달.
- 새32규칙판은 별도 미완 작업이다. 기존게임/새40게임을 임시 독립경제로 바꾸지 않는다. 이것은 요구 취소가 아니라 검증된 수정과 미완 규칙의 분리다.
- 2013 계산기 원본 XLS를 공개 Naver 첨부에서 다운로드해 수식만 안전 파싱했다. 매크로 실행 없음. 기본 데이터·수식 검산306건, 일부 독립 건물 조합 통행료는 2015 카이로 관찰1건과 일치하지만 다른 조합의 모든 실게임 확인은 아님.
- 독립 검토에서 카드 위기→대출→정산 연결 오류를 재현했고 수정 중이다. 테스트 통과 수만으로 승인하지 않는다.


## 후속 구현과 원작 근거의 구분
- 신규 기본 지도는 world-islands-32-v1이다. 18도시와 8관광섬, 황금열쇠 3칸, 출발·무인도·세계여행 각 1칸이며 원작 한국맵과 같은 배열이라고 주장하지 않는다.
- 도시 가격은 추출된 고전 계산기 18행을 순서대로 세계 도시 이름에 대응했다. 시작금 3000과 월급 450은 역사적 퍼스트 자료의 표시단위 환산이며 계산기 자체의 시작금 공식이 아니다.
- 관광섬은 고정 매입150·통행료120·매각75, 일반 건설과 인수 불가이다. 방문 성장 규칙은 적용하지 않는다.
- 새 승리 판정은 라인·컬러그룹3개·관광섬 전체·파산·120턴 결산이다. 관광섬8개 전체와 구매 가능한 모서리16을 세 번째 줄에만 포함하는 것은 이 지도에 맞춘 명시적 적용이다.
- 기존 40칸 저장 방의 좌표·소유권·경제는 보존한다. 새 지도는 새 게임부터 적용된다.
- 전체칸 직접 세계여행, 랜드마크 정전 허용은 사용자 변경 요구를 적용했다. 정전은 기존 다음 본인 방문1회 절반 규칙이며 과거 한국맵의5턴 정전과 동일하다고 주장하지 않는다.
- 캐릭터·유료 아이템 보정은 사용하지 않는다. 대출·카드16종·여행/탈출비100·턴제한은 기존 커플판 규칙이며 완전한 원작 복원으로 표시하지 않는다.
- 최신 개발 검증과 배포 검증은 별도다. 자동 테스트만으로 실제 화면/온라인/원작 일치를 인증하지 않는다.
