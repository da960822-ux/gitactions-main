## 자산 업그레이드:48장 유지 + 보조 아트15개

## 실행 순서와 역할

1. **핵심 행동 흐름부터**: root가 공개 표시 상태·타임라인·재접속 정책과 완료 기준 확정. Sol이 실제 매칭 경로·한 번만 보이는 패·도착 시 점수·턴 표시 구현. 게임 엔진/기존 점수표는 보존.
2. **판과 조작**: Sol이768px 높이 판, 획득 상세, 키보드, 이름 붙은 결과·기존 동의 재경기를 구현. 설명은 게임 아래 유지하고 족보에서 해당 설명으로 연결/복귀할 수 있게 한다.
3. **아트와 Foley 가족**: root가 작은 실제 크기 샘플 승인. Sol이 등판/재질/프레임 방향과 실제 적용을 맡고, Luna가 규격·명명·파생 파일·목록·한글/스페인어 연결을 반복 작업. 창의적인 전체 아트 방향을 Luna에게 맡기지 않음.
4. **검수**: Luna가 각 실제 상태/두 좌석/KO·ES/1366·1440·1920/중복 클릭·정상/재접속/축소모션을 반복 검사. root가 실제 Room 정상 모션과 소리를 직접 검토. 테스트 통과와 감각적 승인 둘 다 필요.
5. **성능**: 릴리스 빌드의 deal/4장 획득/재접속에서 프레임 시간·long task·복제 DOM 정리·메모리를 측정. 목표60FPS(16.67ms),150ms 넘는 조작 지연 없음. 기록 없이 ‘더 빨라졌다’고 보고하지 않는다. 병목이 증명되기 전 Pixi/Three/풀링/엔진 전환 없음.

현재329/41 통과는 이 새 완료 기준의 대체물이 아니다. 특히 기존 검사에서 바닥 중심까지 이동이 통과하더라도, 실제 맞는 패에 놓였는지·이미 정적 카드가 중복 표시되는지·소리가 함께 맞는지는 별도 확인해야 한다.
