# 8개 게임 UI/UX 검토와 수정 — 2026-10-23

## 범위와 판단

기존 게임의 그래픽 재료감과 규칙을 유지하며 실제 조작을 방해하는 부분을 수정했습니다. Impeccable의 critique, layout, clarify, harden, typeset 지침과 프로젝트 game-ui-ux 지침을 적용했습니다. 독립 시각 검토와 루나의 소스·접근성 조사 후 수정하고, 실제 브라우저로 다시 확인했습니다.

홈의 최신 배포 소스 b2facef0를 먼저 통합했습니다. 도미노 Lisbeth 규칙, 숨겨진 손패, 기존 접근 정책은 변경하지 않았습니다.
