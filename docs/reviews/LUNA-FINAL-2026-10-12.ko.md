1. 캐치마인드 전송 대기열: 방 화면의 React key에 재접속 epoch/connection이 들어가 동일 라운드에서도 화면을 재마운트할 수 있었다. 캐치마인드에 한해 방·좌석·게임 key를 유지한다. 내부 방·좌석·라운드·phase·deadline 검사로 새 라운드의 오래된 선을 차단하며, 다른 게임의 기존 재접속 key는 유지한다.
2. 검증 서버 오류 형식: 실제 Edge Function의 `409 {error:'stale_state'}`와 달리 fixture가 `400 {code,message,...}`를 반환해 클라이언트의 새로고침/재시도가 실행되지 않았다. action endpoint만 실제 형식에 맞추고 SQL RPC 오류 형식은 보존한다. 생산 클라이언트·타이머·게임 규칙은 변경하지 않는다.
3. 오프라인 구간에 전체 페이지 스크린샷을 찍었던 실행에서는 HMR을 꺼도 컴포넌트 재마운트와 큐 손실이 재현됐다. 같은 검증에서 오프라인 캡처를 제거하자 재마운트 없이 두 선의 실제 수동 재전송이 통과했다. 페이지 재탐색·timeOrigin·데스크톱 media 변경은 관찰되지 않았으며, 캡처가 정확히 어떤 경로로 재마운트를 유발했는지는 미확정이다. 실패 증거를 지우지 않고 검증 환경의 제한으로 기록한다.
