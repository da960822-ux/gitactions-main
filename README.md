# Yeonseok & Lisbeth · 우리 둘의 게임 홈

연석과 리스벳을 위한 한국어·스페인어 개인 게임 선물입니다. 유일한 메인 디자인 기준은 [현재 비공개 홈페이지](https://yeonseok-lisbeth-review-20261021.pinktrout1024.chatgpt.site/#games)의 최신 우주·커플·게임방 구성입니다. 예전 에메랄드 랜딩과 독립 디자인 프리뷰는 제거했습니다. 홈의 편지·스토리와 여덟 가지 게임은 이 루트 앱에서 함께 관리합니다.

다른 세션에서 이어서 작업하려면 [작업 인계 기록](docs/SESSION-HANDOFF.md)을 읽으세요. 테스트 통과와 화면 검수 결과를 구분하고, 자산 출처·게임 규칙·접근 제한을 함께 보존합니다.

## 실행

```sh
npm ci
npm run dev
```

Supabase 환경변수가 없으면 **같은 브라우저 연습 모드**입니다. 좌석 1/2를 바꾸어 양쪽 행동을 확인할 수 있습니다. 다른 기기의 온라인 접속이나 실제 자동번역이 동작하는 것처럼 표시하지 않습니다.

```sh
npm test
npm run build
```

## 온라인 연결

Supabase 프로젝트 `yeonseok-lisbeth-games`의 DB, 익명 로그인, Edge Function과 번역 비밀값은 설정되어 있습니다. 기존 ChatGPT Site는 소유자 전용으로 배포되며, 아래 온라인 검수는 revision 19에서 확인한 기준 기록입니다. 실제 Site 주소에서 별도 Supabase 익명 사용자 두 명의 방 생성/참가와 양측 캐치마인드 시작을 확인했습니다. 한국어 2건과 스페인어 2건의 일반 채팅 모두 Google 번역과 원문 표시가 통과했습니다. 해파리 그림 9획이 상대 Chrome에 실시간 동기화되고, 스페인어 `medusa` 정답과 양측 1점 반영도 통과했습니다. 서비스 역할 키와 번역 API 키는 서버에만 보관합니다. 자세한 설정과 후속 CLI 이력 복구는 [배포 안내](docs/DEPLOYMENT.md)를 보세요.

## 실제 기능

- 다빈치 코드, 캐치마인드, 도미노, 자이푸르, 스플렌더, 민화투, 독립 보드게임 부루마블 버전, 뮤직톡톡.
- 초대 링크로 접속하는 비공개 2인 게임방, 캐치마인드에서만 한국어·스페인어 채팅 번역, 원문 보존, 7일 만료.
- 별도 비공개 초대 공간인 남편에게 / Para mi esposo 메모함. UUID 초대로 입장한 p1(Papi)과 p2(Mami) 모두 메시지·게임·기능 제안을 작성하고 조회하며, p1만 상태를 바꿉니다. 게시물은 각각 작성 7일 뒤 삭제되며 공간은 유지됩니다. Supabase 없이 쓰는 경우 같은 브라우저의 로컬 저장만 가능하며 공유되지 않습니다.
- 뮤직톡톡은 원본 SWF와 Ruffle 실행 화면을 제공합니다. 게임 파일은 수정하지 않았고 브라우저 호환성과 재배포 권리는 확인이 필요합니다.

새 도미노 게임은 Lisbeth 규칙 v2를 사용합니다. 기본 목표는 200점이며 100점을 선택할 수 있고, 카피쿠아는 +30점, 파소 코리도는 없습니다. 자세한 한국어·스페인어 안내와 v0/v1 저장 게임 호환성은 [도미노 규칙 안내](docs/DOMINO-LISBETH.md)를 보세요.

홈의 번역 예시는 정적인 설명용 그림이며, 실제 대화처럼 보이거나 입력할 수 있는 UI가 아닙니다. 홈과 자이푸르·스플렌더 보드에는 생성한 장식 그림을 사용합니다. 스플렌더 카드 이미지는 엔진 카드의 비용·점수·보석 조합에 맞춰 연결했고, 민화투는 엔진 덱 48장과 일대일로 연결한 출처 표기된 CC BY-SA 4.0 화투 그림을 씁니다. 원작보다 그림이 낫거나 동등하다고 주장하지 않습니다. 음성 채팅, 공개 매칭, 장기 전적, 결제·베팅, 미구현 게임 기능은 제공하지 않습니다.

## 자산과 배포 한계

[프로젝트 규칙](AGENTS.md)의 Ponytail은 모든 에이전트에게 적용합니다. [디자인 설명](DESIGN.md), [자산 출처](docs/ASSETS.md), [리듬게임 출처·호환성](docs/RHYTHM.md)을 확인할 수 있습니다. 장미와 게임 아틀라스는 정적 장식 이미지이며 실시간 3D 장면이 아닙니다. `public/` 파일은 사이트에 접근할 수 있는 누구나 URL로 열 수 있으므로, 호스팅 접근은 기존 소유자 전용으로 유지합니다. Supabase 방 인증은 공개 이미지 파일을 보호하지 않습니다.
