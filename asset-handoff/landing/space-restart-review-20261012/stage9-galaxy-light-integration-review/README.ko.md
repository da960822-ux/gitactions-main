# 은하계 조명과 하트 풍선 재질 비교

이 묶음은 하트 풍선의 색과 반사광을 현재 보이는 나선 은하 배경에 연결하고, 깊이에 따른 크기·거칠기·밝기 차이를 둔 UI 시각 검토 자료입니다. 게임/랜딩 화면의 아트 방향을 유지하며 새 장식 요소를 추가하지 않았습니다.

## 비교 캡처

- `before-d72f11d-1440x900.png`: 기존 기준 화면. 미디어 브랜치 `local/landing-review-media-20261012`의 커밋 `013c44e`에 있는 stage8 캡처를 그대로 사용했습니다.
- `after-d02d215-1440x900.png`: 코드 브랜치 `local/heart-balloon-material-review-20261012`, 정확한 커밋 `d02d215910e87eceaac3ddd95ed85c508188564c`의 로컬 렌더를 새로 캡처했습니다.
- `side-by-side-2880x948.png`: 위 두 원본을 축소/크롭 없이 나란히 놓은 비교용 합성 이미지(각 이미지 위 48px 라벨 포함)입니다.
- `after-d02d215-state.json`: 새 렌더의 뷰포트와 씬 상태, 자산 오류 기록입니다.

두 캡처 모두 1440×900, DPR 1, 스크롤 0, 입장 상태 1.0, 카메라 `[0,0,9.4]`, 하트 인스턴스 48개이며, 움직임을 멈춘 정지 프레임입니다. 전후 파일은 각각 원본 해상도 그대로 제공됩니다. 애니메이션/드래그 동작 비교 영상은 포함하지 않았습니다.

## 검토 요점

- 은하 배경의 자주·장밋빛을 넓은 환경광으로 풍선에 반영해, 기존의 균일한 플라스틱 반사와 분리된 조명을 줄였습니다.
- 뒤쪽 풍선은 더 작고 거칠며 반사광이 약하고, 가까운 풍선은 장밋빛/진주빛 재질을 유지합니다. 인물 초상화 중앙의 가시성도 확인 대상입니다.
- 프레임은 Chromium의 WebKit WebGL 호환 경로와 SwiftShader 소프트웨어 렌더러에서 생성했습니다. 실제 GPU/브라우저 간 색 차이는 여기서 검증하지 않았습니다.
- 페이지에서 기록된 유일한 오류는 `/favicon.ico` 404입니다. 캡처된 화면 내 게임 아트 자산 로드/디코딩 실패는 기록되지 않았습니다.
