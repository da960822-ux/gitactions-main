- 뷰포트: Chromium 1440×900, DPR 1, 소프트웨어 WebGL

`game-section-720.png`는 최종 코드의 scrollY=720 데스크톱 실제 브라우저 화면이다. `idle-before.png`와 `idle-after-10s.png`는 같은 위치/상태에서 10초 간격으로 캡처했다. 화면 상단에서 캔버스가 뷰포트에 고정되어 있고, 오른쪽 게임 소개 문장이 16px로 표시되는 것을 확인할 수 있다.

`scroll-idle-short.mp4`는 최종 코드에서 3초 idle → 휠로 0→720px 스크롤 → 2.5초 idle → 휠로 복귀한 짧은 실제 브라우저 캡처다. 크로미움 CDP가 수집한 39개 뷰포트 프레임을 5fps H.264로 인코딩했다(7.8초). 전체 stage5 영상은 재녹화하지 않았다. 정밀 단일 프레임 확인은 PNG 세 장을 기준으로 한다.

10초 idle 비교에서 화면 상단 760px 영역 1,094,400픽셀 중 202,697픽셀(18.52%)이 RGB 최대 채널 차이 8을 넘었고, 112,395픽셀(10.27%)은 차이 24를 넘었다. 장면은 48개 하트와 720개 별을 유지한다.

`capture-report.json`에는 스크롤 시작·끝 위치, 캔버스 고정 위치와 브라우저 오류 결과가 있다. 실제 GPU 성능은 이 소프트웨어 렌더링 환경에서 판정하지 않았다.
