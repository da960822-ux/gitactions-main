# Cosmic first-screen refinement V2 — 로컬 검토, 미승인

기존 Hero와 cosmic-study V1을 실제로 열어 확인한 후 같은 시안을 보완했다. 원본 인물 투영·크기와 메인 카피·CTA·실제 이야기 유지. 검은 왼쪽 판과 인물 옆 ivory 조각은 정적 구도에서 제외하고 원본 우주 배경을 왼쪽에도 연속시켰다. 왼쪽 어두운 버건디 그라데이션으로 가독성 확보. Baby 190→174px, 한국어 126→116px, 상단 로고와 본문 왼쪽 125px 정렬. 원화 얼굴은 재생성·색보정하지 않았고 외곽에만 약한 CSS glow. 바닥은 기존 실제 화면 클립에 버건디 색을 더한 것으로 새 반사·깊이 검증이 아니다.

개인 로컬 디자인 판단: V1의 판/배경 경계가 사라져 풍부한 배경과 인물이 더 통합된다. 다만 바닥 반사는 여전히 기존 공간 캡처여서 새 배경과의 물리적 일치는 검증되지 않았다. 이후 실제 구현 시 장면의 전경/중경/후경과 물리 조명이 필요하며 정적 배경만으로 Lusion식 공간 전환 달성을 주장하지 않는다.

산출물: compare.html, cosmic-study.png(1920×1080), current.png, refine.py, capture.mjs. 제품 소스 수정 없음. 기존 V1/소스/모델/영상 삭제 없음. 렌더·베이크·장시간 녹화·성능 측정·업로드·푸시·배포 없음. 사용자가 이미지를 보지 못했으므로 시각 승인 대기.

읽기 전용 전송 진단: 기존 batch JSON/로그 2건은 transfer_failed 및 file transfer failed를 보존한다. 이전 도구 응답의 PUT Forbidden은 상태 기록에 남지만 이번에 읽은 batch 원시 JSON/로그에는 HTTP 상태코드·응답 본문이 보존되어 있지 않다. 따라서 HTTP403/만료/네트워크 제한/명시적 Library 권한거절 중 어느 하나로 확정할 수 없다. cosmic-study V1/V2 파일은 전송 시도 자체가 없으므로 거부 대상으로 분류하지 않는다. ZIP의 별도 자동 권한 심사 거절은 PNG 전송 오류와 분리한다. 현재 공식 Library 도구와 스킬은 prepare/finalize 또는 지원되는 직접 create 경로를 제공한다. 도구의 존재는 전송 복구나 사용자 권한 결함의 증거가 아니다. 사용자에게 새로운 권한 승인을 요구할 근거는 확인되지 않았으며 기존 차단을 우회하거나 다른 경로로 재시도하지 않았다. 플랫폼의 공식 전송 기능 복구/지원 확인이 필요하다.
