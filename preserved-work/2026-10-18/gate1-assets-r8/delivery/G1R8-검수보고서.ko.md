# Gate 1 R8 v4/v5 중간 검수 — 승인된 최종안 아님

현재 구현 권한은 Gate 1에 한정됩니다. Gate 2에 진입하지 않았습니다. R6·R7 기준 작업과 별도 게임 작업은 건드리지 않았습니다. 활성 전체 페이지는 previewSpaceV4입니다. v5는 독립 WebGL 실험이며, 전체 페이지 캡처에 한해서 브라우저 모듈 응답을 V5로 바꿨습니다. 이 차이를 소스에 적용한 것으로 보고하지 않습니다.

## 이번 피드백 대응
- 인물 아래의 별도 사각 받침·장식 프레임: v5 GLB에서 모두 제거했습니다. 동일 연속 바닥 메시의 실제 정점에 최대 0.48m 높이장을 적용합니다. 인물이 뒤로 이동할 때 높이장도 따라갑니다. 사진은 승인 원화 그대로입니다.
- 접점: 실제 알파 판정 인물 그림자와 바닥 수광을 추가했습니다. 원래 면광원의 위치·색·면적을 사용한 SpotLight 근사입니다. 정확한 면광원 그림자라고 주장하지 않습니다. 현재 거친 바닥 음영과 인물 하단의 수평 절단이 남아 접지감 합격이 아닙니다.
- 카피 영역: 왼쪽 앞 공간에 실제 월드 좌표 기준 어두운 버건디 재질을 적용했습니다. 인물 이미지를 재생성하거나 보정하지 않았습니다. 실제 staged 전체 페이지에서도 카피 상단은 어둡지만 하단 배경이 여전히 밝습니다. 대비 복원은 완료가 아닙니다.
- 오른쪽 인물 뒤 잘린 실루엣과 멀리 막힌 벽처럼 읽히는 곡면은 아직 해결 완료가 아닙니다. 연속 복도 콘셉트를 유지합니다.

다음 핵심 설계는 강체 힌지를 모핑으로 포장하지 않고, 동일한 연속 표면의 경계·접선·법선을 유지한 실질적인 변형으로 발전시키는 것입니다. 현재 바닥 변형은 접지 문제를 위한 실험입니다. 영상 패널로 확장되는 별도 표면과 같은 공간의 연결을 아직 구현 완료로 세지 않습니다.

## 검증 결과와 한계
- v4 실제 전체 페이지: 1920×1080 DPR1, 0/.3/.43/.5/.65/1 및 역 .3/0, 스페인어 캡처 완료. 콘솔 오류 0, 가로 넘침 0, es-DO 확인. p0와 p.3의 정·역 PNG는 각각 바이트 동일합니다. 첫 방문 인트로는 명시적으로 건너뛴 returning-visit 검수입니다.
- v5 독립 실제 WebGL: 960×540, p0/.3/.5/1 및 역 .3/0 여섯 프레임 완료. 콘솔 및 GL 오류 0. 독립 공간 캡처는 전체 UI 검수와 구분합니다.
- v4 GLTF 중간 프레임 감사: 유한하지 않은 정점 0, 퇴화 삼각형 0, 뒤집힌 삼각형 0. 자기 교차 전체를 증명한 검사는 아닙니다. 이 결과를 v5 정점 갱신 전체 감사로 전용하지 않습니다.
- v5 높이장: 해석적 기울기와 유한차분 비교 및 Jacobian 양수, 별도 stage 노드 부재 테스트를 추가했습니다. Hero 테스트 총 23개 통과, 프로덕션 빌드 통과. 기존 v4 구조 테스트가 v5 시각 품질을 보증하지 않습니다.
- 보호 대상 2,255개 SHA-256 비교: 변경·누락 0. 원본/R6/R7 Git 작업 트리는 깨끗합니다. 게임·API·언어·편지·건의사항·패키지·락 파일 수정, 푸시, 배포 없음.
- 실제 렌더러는 Chromium ANGLE/Vulkan SwiftShader입니다. GPU 가속 환경이나 60FPS를 주장하지 않습니다. v5 동기식 render+readback은 첫 약20초, 이후 약2.4–4.4초였습니다. 디스플레이 FPS와 동일한 수치가 아닙니다. 영상 파일 25fps도 렌더링 25fps 증거가 아닙니다.
- 현재 모바일/1440 검수와 새 v5 실제 브라우저 동영상은 아직 없습니다. 기존 R7 기술 수정 동영상과 v5 공간 실험을 혼동하지 않습니다.
