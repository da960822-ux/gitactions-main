# Gate 1 V6 실험 검수 — 진단 요약 (소스 미포함)

Gate 1 구현·수정 권한 범위에서 동일한 연속 복도 콘셉트를 수정했습니다. 활성 AcrossHero는 여전히 V4이며, V5/V6를 완성품으로 병합하지 않았습니다. V6 전체 페이지는 브라우저의 해당 Hero 모듈 응답만 V6으로 바꾼 임시 검수입니다. 게임·API·언어·편지·갤러리의 구현은 변경하지 않았습니다.

## 먼저: 정확한 Library 차단 내역

| 단계 | 대상/결과 |
|---|---|
| Library prepare_uploads | 진단 PNG `G1R8-v4-arrival-reverse-spanish-v5-staged.png`와 한국어 보고서 `G1R8-검수보고서.ko.md`; 준비 응답은 성공 |
| PNG 전송 | `PUT` → `sdmntprsoutheastus3.oaiusercontent.com` → `Put "[서명 URL 생략]": Forbidden` |
| 보고서 전송 | `PUT` → `sdmntprwestus.oaiusercontent.com` → 같은 Forbidden |
| helper 최종 결과 | 두 파일 모두 `status: failed`, `error_code: transfer_failed`, `message: file transfer failed` |
| 저장 완료 처리 | finalize_uploads 미호출. 새 Library 파일 ID 없음 |

소스 ZIP을 포함한 네트워크 권한 재시도는 자동 승인 검수에서 비공개 코드/자산 업로드 권한·대상 신뢰가 충분하지 않다는 이유로 거절됐습니다. 이후 소스 ZIP을 제외한 진단 두 파일만의 네트워크 권한 호출은 허용됐으나 전송은 위 Forbidden으로 실패했습니다. 부모의 최신 지시에 따라 소스 ZIP은 로컬에 보존하며 다시 업로드하지 않습니다. 다른 저장소, 직접 전송, 우회 경로를 사용하지 않았습니다. 서명 URL·토큰·소스 코드는 이 진단에 포함하지 않았습니다.

## 실제 변형의 증거

강체 힌지는 두 점 사이 거리를 보존합니다. 새 변형은 반경이 다른 두 점 사이 거리가 달라져 강체 회전과 구분됩니다. 같은 입력 좌표에는 같은 변형을 적용해 흰 표면과 매입 선의 흐름을 맞춥니다. 각 반경의 각도만 바꾸는 함수의 Jacobian 행렬식은 1이며, 반경은 보존됩니다. 테스트로 해석적 도함수와 유한차분을 비교했습니다. 변형하는 바닥에도 같은 방식으로 실제 정점과 법선을 갱신합니다. 화면 편집이나 영상으로 변형을 흉내 낸 것이 아닙니다.

실제 내보낸 GLTF와 렌더러가 사용하는 동일한 TypeScript 변형 함수를 기준으로 p=0/.15/.3/.43/.65/1의 정점·법선을 감사했고, 변형하는 형상은 51개 진행률에서도 추가 검사했습니다. 최신 폭 조정 모델에서 유한하지 않은 값 0, 퇴화 삼각형 0, 법선에 반하는 삼각형 0입니다. 원경에 추가한 네이티브 구조물 10개도 열린 경계·비다양체 모서리 0을 확인했습니다. 이 검사는 전체 객체 간 충돌이나 모든 자기 교차를 증명하지 않습니다. 형상 검사가 미적 합격도 아닙니다.

앞선 길고 얇은 베벨 삼각형 오류는 발견 즉시 실패로 기록했습니다. 세분화 시도는 퇴화 삼각형을 만들어 폐기했고, 바닥만 길게 돌출되던 오른쪽 곡면의 시작 깊이를 전체 높이에 맞춰 근본 형상을 바꿨습니다. 실패 로그·캡처도 보존했습니다.

## 검증·보존·남은 일

- Hero 테스트 27개 통과, 저장소 빌드 통과. V6는 임시 모듈이라 최종 프로덕션 통합 빌드 검증으로 세지 않습니다. 원경 추가 후 모델 계약 테스트도 별도로 확인했습니다. 완료 로그를 로컬에 보존했습니다.
- 보호 대상 2,255개 파일의 SHA-256 비교에서 변경/누락 0. 원본/R6/R7 작업 트리는 깨끗합니다. 승인 원화 해시도 그대로입니다.
- 별도 게임 작업, 패키지·락 파일, 푸시·배포는 변경하지 않았습니다. 기존 V4/V5 자료와 비공개 ZIP도 보존했습니다.
- 실제 렌더러는 Chromium ANGLE/Vulkan SwiftShader. 하드웨어 GPU 성능과 60FPS를 주장하지 않습니다. 1920 소프트웨어 렌더링은 매우 느려 성능 합격이 아닙니다.
- V6 전체 페이지의 실제 Hero·중간·도착·복귀·스페인어 캡처를 보존합니다. 임시 모듈 교체를 사용한 검수이며 최초 방문 인트로는 명시적으로 건너뛰었습니다.
- 최신 Hero의 넓고 인공적인 전경 반사가 남아 있습니다. 전경 곡면의 미적 형태·반사 품질, 공간의 최종 재질 디테일, 실제 움직임의 매끄러움은 계속 검수해야 합니다. 현재 사용자/총괄 시각 승인은 없습니다.
- Remotion 새 인트로, 영상 패널 모핑, 최종 영상·실시간 3D의 연속성은 미완료입니다. 기존 비활성 인트로를 완료로 세지 않습니다. 모바일/GPU 최종 검수도 남아 있습니다.

Gate 1을 완료로 처리하거나 Gate 2로 진행하지 않습니다. 소스 ZIP 업로드도 재시도하지 않습니다.


## 다음 수정 대상 — 기존 권한 범위 유지

전경의 굴곡이 별도 단상처럼 보일 가능성과 넓고 인공적인 반사가 남아 있습니다. 같은 버퍼를 쓴다는 구현 사실만으로 접지감이 완성됐다고 판단하지 않습니다. 곡면 법선과 실제 공간을 따르는 반사 방식을 비교하고, 원화 알파·가림·접점 그림자가 정확한지 검수합니다. 기존 반사 효과를 삭제해서 문제를 숨기는 방향은 채택하지 않습니다. 이어 실제 재질 디테일과 조명을 다듬고, 최초 진입·포인터·정/역스크롤·표면 변형·복귀를 실제 브라우저 녹화로 확인해야 합니다. 스냅샷과 수학 검사만으로 Gate 1을 완료하지 않습니다.


## 최신 실제 캡처 완료 결과

1920×1080 DPR1, p1→p0→p.3→p.65→p0와 스페인어 화면을 모두 캡처하고 직접 확인했습니다. 콘솔 오류 0, 실패 0, 가로 넘침 0, es-DO 확인. p0와 복귀 p0 PNG는 바이트 동일합니다. 모든 원본 PNG와 관찰 JSON, 촬영 시 모델/런타임 해시는 `space-v6-annex-page/`와 `v6-annex-capture-manifest.json`에 보존했습니다. 첫 방문 인트로를 건너뛴 임시 검수입니다. 원경 광선 검사에서도 약 306–318m 깊이의 실제 구조물이 교차함을 확인했습니다. 평면 배경으로 덮지 않았습니다.

비교 PNG는 V4 거절된 체크포인트와 V6 실험을 나란히 놓은 진단 자료입니다. Hero는 같은 카메라 구도이며 Arrival은 카메라 시선이 변경됐다고 표시했습니다. 영상 편집 결과가 아닙니다. 새 V6 실제 인터랙션 녹화는 아직 없으며 이전 R7 동영상으로 대체하지 않습니다.
