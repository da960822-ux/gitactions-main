# C — 우리 둘의 빛나는 인쇄실

1920×1080 정적 아트 디렉션 비교 시안이다. 제품 구현이나 실제 WebGL·모션 증거가 아니다.

- `hero.png`: 승인 캐리커처를 가장 큰 초점으로 두고, 버건디 잉크 면·아이보리 종이·로즈골드 박 가장자리를 겹친다. 원본 인물의 따뜻한 빛과 배경의 왼쪽 위 조명을 맞춘다. 활자가 공간 오른쪽의 어두운 면을 점유하고 앞쪽 종이가 인물의 아래를 가린다.
- `arrival.png`: 같은 재질 계열이 깊고 밝은 두 사람의 놀이 자리로 펼쳐진다. 인물을 반복 배치하지 않는다. 한국과 República Dominicana가 서로 다른 종이면에서 같은 놀이 자리로 연결된다. 도미노와 말은 공간의 목적을 제안하는 시안 소품이며 실제 게임 UI가 아니다.
- 선택 이후 구현할 전환 제안: Hero 전경 종이의 가장자리가 회전축을 달리해 펴지고, 잉크면이 안쪽으로 접히며 밝은 내측 공간을 드러낸다. 카메라는 종이의 틈을 통과한다. 타이포는 종이 표면의 인쇄 레이어로 깊이에 따라 가려진다. 인물은 최초 공간에 남는다. 이 전환은 아직 구현하지 않았다.
- Hero 도착·인계 범위만 제안한다. 이후 놀이 테이블 기능은 별도 담당 범위다.

실제 사용: 환경 전용 image_gen 신규 생성 2회, 기존 승인 WebP 복사, HTML/CSS 합성, 기존 로컬 Gowun Batang/DM Sans, 시스템 Playwright/Chromium 정적 캡처. 생성 도구에 승인 인물 이미지를 전달하지 않았다. 배경에는 인물·문자·UI를 생성하지 않았다. 새 얼굴 생성 없음.

원본 캐리커처 SHA256: `72a0010ae5960d33e62b4678715bfd1df71e3d8f743248c69eeb4c5c1c55b318`. 복사본도 동일. CSS의 위치·크기·그림자만 사용하며 얼굴 픽셀을 수정하거나 색 보정하지 않았다.

`hero.html`, `arrival.html`, `styles.css`와 자산은 이 폴더에만 있다. 제품 파일, 패키지, Git, 기존 게임, 편지 및 번역에 변경 없음. 서버·WebGL·영상녹화 미실행. `file://`는 환경 정책으로 차단돼 Playwright request fulfilment로 로컬 파일을 읽었다. 네트워크 서버를 열지 않았다.

검증: CSS viewport와 출력 모두 native1920×1080, DPR1. 모든 이미지·폰트 로드, CTA가 화면 안에 있음, pageerror0 확인. 두 PNG를 눈으로 확인했다. 작은 다분할 이미지는 만들지 않았다.

미검증 및 위험: 생성 환경은 재질·빛·구도의 목표 이미지다. 실제 3D 메시, 동적 광원, 카메라·표면 변형, 역스크롤·모바일·성능·접근성은 구현하거나 검증하지 않았다. 선택되면 목적에 맞는 3D/재질 자산으로 실제 공간을 제작해야 한다. 생성된 잉크 꽃무늬는 실제 추억을 의미하지 않는 장식이며, 과도하게 느껴지면 아트 디렉션 검수에서 교체할 대상이다. 사용자 선택·승인 전 복잡한 모션 구현 금지.

메인 검수 후 HTML 마무리: 두 화면 상단에 우리 이야기·게임·편지·건의사항 텍스트 내비를 추가했다. 시안에서는 정적 메뉴이며 실제 라우팅을 구현하지 않았다. Arrival의 두 언어 표시는35/33px로 키우고 명암 대비를 높였다. 두 개의 얇은 인쇄선이 놀이 자리의 공통 지점에서 만나도록 SVG를 합성했다. 환경/인물은 재생성하거나 수정하지 않았다. 재캡처 후 두 PNG를 다시 눈으로 검토하고 native1920×1080·전체CTA·pageerror0를 재확인했다.
