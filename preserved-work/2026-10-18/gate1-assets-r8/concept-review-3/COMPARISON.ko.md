# Hero 재선택 — 세 가지 정적 아트 디렉션

이번 자료는 V18/V19를 더 다듬은 결과가 아니라, 사용자 선택을 위한 서로 다른 세 방향의 큰 정적 구도다. 각 방향은 Hero와 도착 공간 두 장이며 최종 PNG는 각각 1920×1080이다. 새 배경은 환경 전용 생성 이미지다. 승인 캐리커처 원본은 별도 HTML 이미지로 합성했고 얼굴 재생성·색 보정은 하지 않았다.

## 비교와 메인 권고

| 방향 | 첫 화면과 도착 공간 | 강점 | 남은 위험 |
|---|---|---|---|
| A — 우주에서, 우리 방으로 | 승인된 우주 배경·큰 커플·세리프 Baby → 버건디 두 좌석, 금속 테이블, 해안 채광의 개인 놀이방 | 좋아했던 첫 화면의 정서를 유지하면서 도착 장소와 목적을 확실히 바꿈. 세 방향 중 가장 친밀하고 직접적인 공간 | 환상적인 우주와 사실적인 실내 사이의 재질·광원 전환을 실제 공유 오브젝트로 설득해야 함. 인물 하단 경계도 실제 전경 지오메트리로 통합 필요 |
| B — 두 지평의 만남 | 햇빛·아이보리 광물·바다·단단한 산세리프 → 푸른 그늘의 곡면 놀이 파빌리온 | 가장 밝고 명료한 대비. 앞·뒤·위로 연결되는 건축 표면과 선명한 원근 | 휴양 공간처럼 읽힐 수 있어 두 사람의 게임·언어 이야기를 실제 인터랙션으로 구체화해야 함. 큰 인물은 테이블 뒤에 고정하고 카메라를 따라오지 않아야 함 |
| C — 함께 펼치는 종이 공간 | 버건디 잉크·아이보리 종이·금박·큰 커플 → 종이가 펼쳐져 만들어진 두 사람의 놀이 자리 | 인물 하단 가림, 타이포, 재질의 결속이 가장 좋음. 하나의 종이가 다음 공간으로 변하는 전환에 가장 명확한 조형적 이유가 있음 | 생성 이미지의 복잡한 접힘을 실제 메시로 다시 설계해야 함. 꽃무늬와 금박 밀도를 통제하고 종이의 얇음·광택·겹침을 실제 렌더에서 검증 필요 |

메인의 우선 추천은 **C**다. 첫 화면의 인물·문장·재질이 하나의 구도로 묶이고, 같은 종이가 휘고 열리면서 다른 장소를 드러내는 연속 변환의 근거가 가장 분명하다. A는 승인된 우주 분위기를 유지하고 싶을 때 가장 적합하다. B는 밝은 낮의 방향을 택할 때 유효하다. 이 추천은 정적 아트 디렉션에 한정하며, Awwwards 수준 달성이나 Lusion식 모션 구현을 확인했다는 뜻이 아니다.

## 선택 후 Hero 범위의 전환 설계

- **A:** 커플은 최초 공간에 남는다. 전경의 금속 경계가 회전하며 실내 테이블 가장자리로 이어지고, 카메라는 경계 안쪽을 지나 새로운 실내로 진입한다. 우주 사진을 다음 방의 벽에 다시 붙이지 않는다.
- **B:** 두 광물 지형의 얇은 금속 경계가 이어진다. 같은 표면이 카메라 위로 휘어 천장을 만들고, 카메라는 밝은 외부에서 그늘의 파빌리온 안으로 들어간다. 도착에는 그림·도미노 소품과 깊이 있는 출구가 남는다.
- **C:** 인물 앞의 종이가 서로 다른 축으로 펴지고 버건디 면이 안쪽으로 접혀 밝은 내부를 드러낸다. 타이포는 종이 표면에 붙은 레이어로 가려지고, 카메라는 틈을 통과한다. 두 나라를 나타내는 종이면이 놀이 자리에서 만난다. 역스크롤에서는 같은 메시·카메라 타임라인을 역행해 최초 구도로 돌아온다.

모두 아직 설계안이다. 이미지 두 장 사이에 실제 공유 메시·카메라·광원·역스크롤 연결은 구현하지 않았다. 생성 배경을 평면에 붙이고 확대하는 방식으로 전환을 완료 처리하지 않는다.

## 이번에 실제로 한 작업과 보존

- A/B/C 독립 담당이 분리된 폴더에서 정적 환경·HTML/CSS 구도를 제작했다. 메인이 방향을 지정하고 여섯 장을 큰 화면으로 직접 검토했다. C는 국가 표기 가독성과 내비게이션을 추가 검수했다.
- 환경 전용 ImageGen, 기존 승인 이미지, 기존 폰트, Playwright/Chromium 캡처를 사용했다. 실제 WebGL·GSAP·Remotion·HyperFrames 모션을 새로 제작하지 않았다. 도구 설치와 패키지 변경도 하지 않았다.
- 기존 V18와 V19 WIP, 소스·영상·자산을 보존했다. V19는 미검수 WIP 상태로 동결돼 있으며 이번 시안으로 제품 화면을 교체하지 않았다.
- 제품의 보호 대상 2,255개 파일을 SHA-256으로 확인해 변경·누락 0개를 확인했다. 별도 게임 작업, 데이터, API, 편지, 언어 연결, 라우트에 손대지 않았다. 이 정적 단계에서 기능을 새로 실행·통과했다고 주장하지 않는다.
- 도착 공간의 게임 소품은 공간 목적을 보여주는 조형 제안이며 실제 게임 상태·UI가 아니다. 해안은 상상 공간이며 실제 여행이나 특정 지역의 재현을 주장하지 않는다.

## 다음 승인 지점

사용자가 A/B/C 중 방향을 고르거나 수정 방향을 전달한 뒤에만 선택된 방향의 실제 Hero 구현을 재개한다. 선택되지 않은 방향에 복잡한 모션을 구현하지 않는다. 선택 후에도 Hero 전체의 실제 포인터·표면 변형·카메라·역스크롤·영상 연결·CTA를 구현하고, 실제 브라우저 영상과 큰 캡처를 제출해 다시 검수받는다. 정적 방향 선택은 Gate 1 완료 승인이 아니다.

실시간 조명, 3D 자산 재구축, GPU 가속 환경 성능, 모바일, 실제 연속 전환은 남은 검증 항목이다. 현재 소프트웨어 렌더링 환경을 실제 GPU 성능으로 추정하지 않는다. Lusion 원본 영상은 접근 실패로 프레임을 직접 관찰하지 못했으며, 사용자가 제공한 타임코드 설명과 실제 관찰을 구분한다.
