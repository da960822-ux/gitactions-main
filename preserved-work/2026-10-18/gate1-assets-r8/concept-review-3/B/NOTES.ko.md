# B — 두 지평의 만남

정적 아트 디렉션 비교용이며, WebGL 구현·모션 검증 자료가 아니다.

- `hero.png`: native 1920×1080. 햇빛이 닿는 아이보리 광물 지형, 바다의 푸른 깊이, 얇은 로즈골드 테두리와 버건디 경로. 승인 캐리커처는 큰 왼쪽 중심, 문구는 오른쪽의 단단한 편집 타이포. 따뜻한 좌상단 광원으로 기존 얼굴의 방향과 맞췄다. 전경의 같은 무대 표면을 HTML 클립으로 앞에 놓아 인물 하단을 가린다.
- `arrival.png`: native 1920×1080. 낮은 곡면과 금속 테두리가 푸른 그늘의 놀이 파빌리온으로 이어지는 도착 구도. 앞의 밝은 외부 전경과 다른 카메라·차광·깊이. 인물 이미지는 반복하지 않는다. 도미노와 드로잉 도구는 함께 놀 공간의 조형적 단서이며 실제 게임 UI가 아니다.
- 전환 설계안: 두 지형의 얇은 금속 경계가 하나의 경로로 연결되고, 같은 광물 표면이 카메라 위로 휘어 파빌리온의 천장과 놀이 표면이 된다. 카메라는 표면 안쪽 그늘을 지나 도착 공간의 빛을 본다. 이 연속 변형은 아직 구현하지 않았다. 선택 후 공유 메시 토폴로지와 실제 조명으로 검증해야 한다.

## 실제 제작

ImageGen으로 사람·문자 없는 환경 두 장만 생성. 원본은 `/workspace/generated_images/exec-e6b36e68-26c7-4ad5-9b3b-e7938b91b61e.png`, `/workspace/generated_images/exec-82cdb550-c4af-4f33-80a2-88a49ddc40f1.png`. 생성 환경 원본은 1672×941이며, 브라우저 최종 합성은 1920×1080이다. 최종 웹용 3D 자산이 아니다.

실제 HTML/CSS가 원본 캐리커처·문구·CTA를 합성한다. Chromium + Playwright, `setContent`로 메모리 합성 후 캡처했다. `file://` 탐색은 관리 정책에 의해 차단됐고 서버는 만들지 않았다. `capture-check.json`에서 1920×1080, 한 장면만 표시, 페이지 오류 0을 확인한다. 두 결과를 직접 열어 확인했다. 추가 라이브러리 설치·제품 소스 수정·영상 녹화·Library 업로드 없음.

캐리커처 원본 SHA256: `72a0010ae5960d33e62b4678715bfd1df71e3d8f743248c69eeb4c5c1c55b318`. 원본 얼굴 재생성·편집·색 필터 없음. CSS 크기 변경과 그림자만 있다.

이 해안은 상상 공간이며 한국·도미니카의 특정 장소나 실제 여행 기억을 재현한다고 주장하지 않는다. 합성 인물은 2D이며 새 포즈도 아니다. 실제 3D 변형, 영상 연결, 포인터, 가속 환경 성능, 모바일, 기능 회귀는 이 정적 비교 단계에서 검증하지 않았다.
