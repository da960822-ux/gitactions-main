# Gate1 V18 기술 후보 보존 및 시각 목표 차이

2026-10-18. **V15는 사용자 불합격. V18도 아트 디렉션 합격본으로 판단하지 않는다. Gate1 승인 아님.**

## 실제 변경과 확인

- 기존 Remotion 소스에 작은 표면용 광선 개봉 composition을 추가하고 3.2초/512×512 MP4를 실제 렌더했다. 실시간 최초 진입 중 같은 WebGL 표면에 사용하고, 스크롤 중 검증한 기존 HyperFrames lightwell 영상으로 이어진다. 이전 전체 공간 Remotion 영상을 화면에 덮지 않는다. 이것은 작은 표면 영상 연결이며 요구한 시네마틱 선물 인트로의 최종 완성은 아니다.
- 하나의 UUID·UV·1225 vertex 메시가 작은 면에서 휘어진 넓은 영상 벽으로 바뀌고 기존 카메라가 이동한다. 역스크롤은 같은 함수로 복귀했다. 단순 영상 확대만으로 실제 geometry 변화를 대신하지 않는다.
- 반복 우주 사진 곡면을 제거하고 실제 곡선 벽·깊은 개구부·금속 이음·바닥과 따뜻한/차가운 면광원을 배치했다. 곡선 벽의 분할을 늘리고 analytic normal을 적용했다. 실제 V18 프레임에는 점선 형태의 조명/그림자 artifact가 여전히 남아 있어 완전히 해결됐다고 하지 않는다. 최초 Hero의 원본 배경·얼굴은 보존했다.
- 잘못 선택한 `folded-playhouse-surface.mp4`에는 각진 판 영상이 들어 있음을 직접 프레임 추출로 확인했다. 실제 광선 내용의 `folded-playhouse-lightwell.mp4`로 연결을 바로잡았다. 파일명과 소스 대응을 확인하지 않고 가정했던 오류다.
- CSS1920×1080과 실제 캔버스 크기를 분리해 캡처했다. 이전 960×540 뷰포트보다 큰 740px 최소 높이가 세로 잘림의 원인이었다. 이번 CSS 전체 프레임에는 Hero CTA가 포함된다.

실제 V18 캡처/녹화는 CSS1920×1080, DPR.25, 내부 WebGL480×270이다. PNG는 브라우저 CSS scale1920×1080, 녹화960×540이다. PNG 저장 해상도를 내부 렌더 해상도로 잘못 보고하지 않는다. 메인·중간·도착을 단독 화면으로 보존했다. 고해상도1440 내부 시도에서는 중간 프레임 대기45초가 만료됐고 별도 기록으로 보존했다.

V18 전체 실제 원본 녹화191.2초는 최초 방문/표면 확장/도착/역복귀를 포함하며 브라우저 오류0이다. 출력 인코더25fps는 앱FPS가 아니다. 소프트웨어 렌더링으로 실제 움직임에 긴 대기·끊김이 있고, 매끄러운 모션 검수 합격이 아니다. 짧은 forward excerpt는 원본94초 부근부터68초를 stream copy한 것이며 속도 변경·생성 프레임·편집 효과는 없다. 원본은 별도로 남긴다.

## 다음 대안: 펼쳐지는 둘의 플레이 테이블 — 아직 구현하지 않음

1. 최초 Hero: 승인 얼굴과 사적인 카피를 중심에 두되 불합격 오브젝트·구도를 보존할 의무는 없다. 작은 선물 면이 개봉되며 해당 면의 seam과 빛이 이후 장면의 표식이 된다.
2. 전환: 인물은 무대에 남는다. 카메라가 가장자리를 실제로 통과하는 동안 영상 면이 휘고 회전하며 수직→수평으로 변하고, 이미 보이던 다음 공간의 테이블 상판에 정착한다.
3. 도착: 두 자리와 실제 게임을 대표하는 소품이 있는 공유 테이블이 중심이다. 다른 조명·재질·외부 풍경이 깊이를 만든다. 같은 커플 이미지/우주 사진을 다시 크게 붙이지 않는다. 게임 구현·갤러리 동작·편지 콘텐츠를 대신 개발하지 않는다.
4. 역행: 같은 geometry·UV·카메라 경로로 상판이 다시 접혀 Hero의 선물 면이 된다. 새 임시 화면으로 점프하지 않는다.

이 대안은 현재 보존 소스에 적용된 것으로 보고하지 않는다. 후반팀의 독립 스토리·편지·이벤트 파일은 계속 분리한다. 사용자/총괄 검수 전 합격으로 처리하지 않는다.
